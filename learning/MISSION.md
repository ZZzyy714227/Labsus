# MISSION — 为什么学这个

## 使命

LABSUS（悬架实验室）是 vibe coding 的产物：代码在对话中长出来，用户只在**功能层面**理解它（会用、会提需求、会看结果），原理层面存在断层。目标：从物理、数学、机械原理的**最底层**完整重建对项目的理解，达到能**独立、完整、准确地向任何人讲述项目中任何一个数学建模与开发细节**的水平——包括推导来源、公式含义、数值方法选择的原因、历史 bug 的根源。

## 背景

- 用户：川陀，FSAE（大学生方程式）语境
- 项目：三代演化（V1→dwb-mod→LABSUS），现主线 = LABSUS 引擎（Python /api/v3）+ 单文件前端
- 起点：功能层理解完好；数学/力学推导层需要从零走一遍

## 成功标准（可检验）

1. **每章费曼口试通过**：不看材料，把该章的物理推导 + 对应代码实现讲清楚，并答住追问
2. **结业全链路亲讲**：从硬点 → 机构求解 → 定位角 → 力链 → 整车载荷转移 → TLLTD，一口气讲 45 分钟，听众提问能接住
3. **能解释全部历史关键 bug 的根源**：GS 不收敛（43-84mm）、TLLTD 线性齐次恒定、N/mm↔N/m 单位错位、Kabsch 语义恢复误差、SolveRocker 分支跳变

## 约束

- 教学语言：中文，术语中英对照
- 教学工件：每章一个 HTML explainer（`learning/explainers/`）+ 学习记录（`learning/learning-records/`）
- 开发暂停（2026-08-22 用户指令："先不做开发了"）；但允许为教学目的运行/小改代码做实验
- 诚实原则：发现项目实现里有物理不严谨处，明确指出并记录（这本身是最好的教材）
