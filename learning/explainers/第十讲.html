10.0 这一章解决的物理问题

第 9 章是稳态（弯道保持住的那一刻）。真实路面是时变的：颠簸让轮载波动，轮载波动 = 抓地力波动（第 8 章 $D \propto F_z$）。本章：① 四分之一车 2-DOF 理论（两个固有频率为什么差一个量级）；② 本项目实现的真实模型边界（诚实声明：车身接地的角台架，不是完整 1/4 车）；③ 元件本构四件套（弹簧/非对称阻尼/缓冲块/单向轮胎）；④ PBD 时间推进——第 4 章投影路线在时域的胜场；⑤ 步长稳定性分析（算出 9.7× 裕度）。

10.1 四分之一车 2-DOF：理论地标

📐 牛顿列方程（每质量一个 FBD）

簧上质量 $m_s$（那 1/4 车身）经弹簧 $k$、阻尼 $c$ 连到簧下质量 $m_u$（车轮立柱），轮胎刚度 $k_t$ 接路面 $r(t)$：

$$m_s \ddot{x}_s = -k(x_s - x_u) - c(\dot{x}_s - \dot{x}_u)$$ $$m_u \ddot{x}_u = +k(x_s - x_u) + c(\dot{x}_s - \dot{x}_u) - k_t(x_u - r)$$

无阻尼固有频率（质量比 $m_s/m_u \approx 10$，$k_t \gg k$）：

$$f_{body} = \tfrac{1}{2\pi}\sqrt{\tfrac{k}{m_s}} = \tfrac{1}{2\pi}\sqrt{\tfrac{61875}{330}} = \mathbf{2.18\ Hz}, \qquad f_{hop} = \tfrac{1}{2\pi}\sqrt{\tfrac{k + k_t}{m_u}} = \mathbf{13.7\ Hz}$$

频率分离的物理：低频时簧下跟着簧上走（车身起伏模态），高频时簧下独自抖而簧上不动（wheel hop 模态，$k_t$ 主导）。调阻尼的目标区间就在两峰之间压平传递率。

10.2 本项目的模型边界（诚实声明）

⚠️ 实现是"车身接地的角台架"，不是完整 1/4 车

逐点核对 HP_META 的 fix 标记与 stepDyn：全部 chassis 节点（含 DMP_BODY）每帧被 setChassis 钉回设计位——车身没有 heave 自由度。运动质量 = 机构节点质量和：

$$m_{move} = 2.0 + 1.5 + 10.2 + 0.9 + 1.2 + 1.5 + 1.2 = \mathbf{18.5\ kg}$$

于是实际模型 = 机构（多节点受约束）+ 对地弹簧/阻尼 + 单向轮胎 + 移动路面，等效主模态：

$$f_{rig} = \tfrac{1}{2\pi}\sqrt{\tfrac{k_w + k_t}{18.5}} = \mathbf{19.65\ Hz} \;(\omega = 123\ \mathrm{rad/s})$$

后果：这个面板看不到 2.2Hz 车身起伏模态（mS=330 只用于弹簧预载与准静态记账，不在动力学里）；它展示的是轮端对路面激励的响应、damper 力、缓冲块打击。读任何仿真先问"哪些自由度被接地了"——模型边界是结论适用范围的母亲。

10.3 元件本构四件套

🎯 逐个对账（stepDyn 真实公式）
元件公式细节与物理
弹簧$F_k = F_0 + k_S(L_0 - L)$，$F \ge 0$$F_0$ = 预载（静态轴荷/$mr$，撑住车身）；$F<0$ 钳零 = 弹簧脱离座（拉杆悬挂/跳台腾空）
阻尼（非对称）$F_c = -(\dot{L} < 0\ ?\ c_B : c_R)\,\dot{L}$压缩 $c_B{=}8$、回弹 $c_R{=}12$ N·s/mm——回弹更硬是调车惯例（吸收后控制回弹防弹跳）。轮端计价 $c_w = c\,mr^2$ ⟹ 阻尼比 $\zeta_{bump}{=}0.50$、$\zeta_{rebound}{=}0.75$
缓冲块越界 $x$（>70mm 或 <−75mm）时 $F = k_{BS} x^2/20$二次渐进：5mm→1.25kN、10mm→5kN、20mm→20kN、30mm→45kN——末段变"砖"。/20 是形状标定常数（第 6 章校准包袱的同族）
轮胎（单向）$pen = z_{road} - z_{cp} > 0$ 才有 $F = k_t pen + c_t \dot{pen}$，$F \ge 0$只能推不能拉（腾空 = 零轮载）；接触阻尼 $c_t$ 抑制穿透振荡
💡 路面信号谱（roadSignal 五种）

step（tanh 软阶跃）= 过路沿/上下台架；sine = 定频共振搜索；pulse（高斯）= 单次冲击（路肩）；chirp（线性扫频 0.4→rF Hz）= 一次跑完频响；rand（5 次谐波伪随机）= 粗糙路。工程顺序：chirp 找共振 → sine 在共振处调阻尼 → rand 验综合。

10.4 PBD 时间推进：投影路线的时域胜场

🎯 每个子步三段循环（stepDyn 结构）
Step 1 力积分（半隐式 Euler）

清力 → 重力 → 弹簧/阻尼力（沿减振器轴）→ 缓冲块 → 轮胎接触力；$v \mathrel{+}= \frac{f}{m}h$，速度钳位 2×10⁴ mm/s（防爆炸保险丝）。先更新 $v$ 再动 $p$（半隐式/辛欧拉——比显式 Euler 对振子稳定得多）。

Step 2 位置投影（12 轮 sweepProj）

$p \mathrel{+}= v h$ 后，约束已被破坏 → 投影回可行流形（第 4 章的簇精确投影：projHinge 整簇刚体旋转、projBody 加权 Kabsch）。

Step 3 速度回推

$v = (p_{new} - p_{old})/h \times 0.99995$——速度从实际位移重导出（PBD 精髓：投影隐式吸掉了约束方向的动量），0.99995 是微量数值阻尼。

为什么时域里投影赢（第 4 章GS 败诉的镜像）：刚性约束 = 无穷刚度，显式积分要求 $h \to 0$；PBD 把"解刚性方程"换成"位置上投影"，在小步长（1.67ms）+ 簇精确投影 + 质量加权下稳定收敛。同一算法族，静力学里输给 TRF（慢、无保证），时域里因为步子小而赢——工具选型看场景，这是全课程第三次重复的结论。

10.5 稳定性分析：步长的数学

📐 显式积分的 CFL 式限制（对最硬模态）

对 $\ddot{x} = -\omega^2 x$ 用显式 Euler，放大矩阵特征值离开单位圈的条件：$\omega h < 2$（半隐式 Euler 同限制但无数值增阻）。本项目最硬自由度 = rig 模态 $\omega = 123$ rad/s：

$$h_{max} = \tfrac{2}{\omega} = 16.2\ \mathrm{ms}, \qquad h_{actual} = \tfrac{16.7\ \mathrm{ms}}{10} = 1.67\ \mathrm{ms} \;\Longrightarrow\; \textbf{9.7 倍裕度}$$

NS=10 子步不是玄学，是对 19.65Hz 模态 + 约束投影精度的定价。若把 $k_t$ 加倍或运动质量减半，$\omega$ 升 $\sqrt{2}$ 倍，裕度降到 ~7×——改参数前先算这道题。

10.6 源码逐行对账（stepDyn 核心）

const NS=10, h=dt/NS;  kS=state.kS*FS; ...        # FS=1000：N/mm→N/m（第1章单位纪律）
for(let s=<NS; s++){
  rz = M.roadZ0 + roadSignal(tt);                        # 路面瞬时高度（10.3 谱）
  节点清力 + 重力 −m·g;
  d = B.p − A.p; L = |d|; u = d/L;  rel = (B.v−A.v)·u;    # 减振器轴向相对速度
  Fk = springF0 + kS*(damperL0 − L);                      # 弹簧：预载+行程
  Fc = −(rel<0 ? cB : cR) * rel;  F = Fk+Fc; if(F<0)F=0;   # 非对称阻尼+防拉穿
  if(tr > bsU)  wheel.f.z −= kBS*(tr−bsU)²/20;      # 上缓冲块（二次渐进）
  if(tr < −bsD) wheel.f.z += kBS*(−bsD−tr)²/20;      # 下缓冲块
  pen = rz − cp.z;  if(pen>0) fz = kT*pen + cT*(rzv−vz); # 单向轮胎
  v += f*h/m (钳位); pp=p; p += v*h;                     # 半隐式积分
  for(it<12) sweepProj(M, null);                        # 位置投影（PBD 核心）
  v = (p−pp)/h × 0.99995;                                # 速度回推+数值阻尼
}

10.7 核心检查点与自测

Q1. 推导 1/4 车两个固有频率；为什么差一个量级？

解析：$f_{body}=\sqrt{k/m_s}/2\pi$（弹簧只对抗簧上质量）、$f_{hop}=\sqrt{(k+k_t)/m_u}/2\pi$（簧下对抗弹簧+轮胎，且质量小 ~10×）。频率 ∝ $\sqrt{k/m}$：分子硬 3.5×、分母轻 10× ⟹ 频率差 $\sqrt{35}≈6$×。

Q2. 本项目 4-Post 面板接地了什么？能看到/看不到什么模态？

解析：chassis 全部节点每帧钉回设计位（含 DMP_BODY）——无车身 heave。看到：19.65Hz rig 模态（轮端对路面）、damper/缓冲块传力；看不到：2.2Hz 车身起伏。mS 只进弹簧预载与准静态，不进动力学质量。

Q3. 为什么回弹阻尼通常比压缩硬？本项目数值？

解析：压缩段要柔（让轮子快速跟上坑，保接触），回弹段要硬（吸收能量后控制车身回弹防二次弹跳）。cB=8/cR=12 N·s/mm ⟹ 轮端 ζ 0.50/0.75——教科书式配置。

Q4. PBD 与第 4 章静力投影是什么关系？为什么时域里它赢了？

解析：同一算法族（位置投影+簇精确+质量加权）。静力学输给 TRF：步长大、迭代多、无收敛保证；时域赢：每子步只走 1.67ms 的微小漂移，投影 12 轮绰绰有余，且天然处理刚性约束（无穷刚度在显式力积分下不可表示，在位置投影下无成本）。

Q5.（动手）把 kT 从 220 改到 440 N/mm（胎压翻倍效果），稳定性裕度变多少？NS 要不要动？

解析：$\omega \propto \sqrt{k_w+k_t}$：281875→501875 ⟹ $\omega$×1.33 = 164 rad/s ⟹ $h_{max}$ = 12.2ms，裕度 9.7→7.3×。仍安全，NS=10 可不动；但若同时减运动质量（轻量化轮心节点）到 ~9kg，$\omega$≈230，裕度 ~5×——建议 NS 加到 16。先算后改。
