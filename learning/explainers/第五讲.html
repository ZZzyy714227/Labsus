第 3-4 章求出了位姿（每个节点在哪、转向节转到哪）。工程师不直接消费坐标——他们消费指标：外倾、前束、主销内倾、后倾、磨胎半径、拖距、瞬心、侧倾中心。本章做四件事：① 把每个指标从几何定义完整推导成公式；② 结清第一讲的账（图算 RC=57.5 vs 引擎 55.3 的差异，并修正备课时的错误归因）；③ 讲解静态量如何通过扫掠 + 中心差分变成增益（外倾增益、弯跳转向、RC 迁移）；④ 转向运动学与阿克曼百分比。途中还有一个真实案例：备课实验抓到过引擎真 bug（5.3，已修复并复盘）。

5.1 轮轴向量 → 外倾 / 前束（第 2 章 2.8 的收尾）

回顾：当前轮轴 $a = R\,a_0$（Kabsch 恢复的旋转作用于设计轴），提取公式与符号行为学：

$$\gamma = -\arcsin(a_z), \qquad \alpha = \operatorname{atan2}(a_y,\, a_x)$$

负外倾为什么是"轮顶向内"：右轮轴指 +X（外侧）；$a_z = -\sin\gamma > 0$（$\gamma<0$）意味着轴的外端上翘 ⟹ 车轮平面（⊥轴）顶部倒向车内。弯道里车身侧倾让外侧轮变正外倾，所以静态给负外倾 + 负外倾增益来补偿——设计外倾 $-1.2°$ 的意义。正前束（$a_y>0$，轴向前偏）= 车轮前端指向车内，两轮"内八字"，增稳。

5.2 主销几何族：KPI / 后倾 / 接地点 / 磨胎半径 / 拖距

📐 推导：主销轴的两个投影角

主销（转向轴）过上球铰 UBJ、下球铰 LBJ，轴向量 $v = \overrightarrow{LBJ \to UBJ}$。前视图（X-Z 平面）里它与竖直方向夹角即 KPI：

$$\mathrm{KPI} = \arctan\frac{\text{上端相对下端的内倾横移}}{\text{高度差}} = \operatorname{atan2}\big(-(u_x - l_x),\ u_z - l_z\big)$$

基线数值：UCA 端内移 $730 - 675 = 55$mm、高差 290mm ⟹ $\mathrm{KPI} = \arctan(55/290) = 10.74°$。同理侧视（Y-Z 平面）得后倾：UBJ 在 LBJ 后方 25mm ⟹ $\mathrm{cast} = \arctan(25/290) = 4.93°$。atan2 保号（前后/内外方向感）。

📐 推导：接地点 cp 的构造（投影公式的第三次登场）

接地点 = 轮心沿"轮平面内竖直向下方向"落到的地面点。轮平面 ⊥ 轮轴 $a$。竖直方向 $\hat z$ 一般不在轮平面内（有外倾时 $\hat z$ 在轴上有分量）——把它投影到轮平面：

$$r = \hat z - a\,(\hat z \cdot a), \qquad \hat r = r / \|r\|, \qquad cp = wc - \hat r \, R_{tire}$$

这与第 3 章"点到直线垂足"是同一个投影操作（去掉沿某方向的分量）。实测效果：外倾 $-1.2°$ 让接地点向外偏移 $R\sin|\gamma| = 325 \times 0.0209 = 6.81$mm——$cp_x = 816.81$ 而轮心 $x=810$。

📐 推导：主销-地面交点 kg、磨胎半径与拖距

主销轴参数化 $p(t) = ubj + t\,(lbj - ubj)$。要求 $p_z = cp_z$：

$$t^* = \frac{ubj_z - cp_z}{ubj_z - lbj_z} \quad (\text{基线} = \tfrac{455+4.9}{290} = +1.586,\ \text{即越过 LBJ 继续向下到地面})$$ $$kg = ubj + t^*(lbj - ubj) \implies \text{scrub} = cp_x - kg_x \;(\text{横向}), \quad \text{trail} = kg_y - cp_y \;(\text{纵向，正 = 轴交点在前})$$

5.3 实战案例：引擎的 kg 符号 bug（已修复，教学即审计）

⚠️ 备课实验抓到的真 bug 复盘（证据链完整，2026-08-22 已修复）

历史异常：引擎设计位曾输出 scrub = 229.0mm、trail = −54.7mm——负拖距配正后倾（4.93°），物理不通；229mm 磨胎半径也大得离谱。（修复后正确值：scrub 54.58 / trail 24.64，与前端逐位一致，测试锁定。）

手算复核（当时）：用引擎的公式 $t_0 = (cp_z - ubj_z)/dz$（$dz = ubj_z - lbj_z = +290$）得 $t_0 = -1.586$，$kg = (587.8, -54.6, \mathbf{914.8})$——交点落在 UBJ 上方 915mm 高空，不在地面！scrub/trail 输出与这个错误 kg 逐位吻合。

对照前端（真实浏览器 playwright 验证）：前端分母是 $(lbj_z - ubj_z) = -290$ ⟹ $t_0 = +1.586$，$kg$ 在地面（$kg_z \approx cp_z$），输出 scrub = 54.5mm、trail = +24.9mm（正后倾配正拖距，自洽 ✓）。

根因：S2-5 移植前端公式时，$t_0$ 的分母被统一成了同时供 KPI/后倾使用的 $dz$——一处符号翻转。修复（2026-08-22 落码 + 2026-08-30 测试锁定）：引擎改为 $t_0 = (ubj_z - cp_z)\,/\,(ubj_z - lbj_z)$，输出与前端逐位一致（golden: scrub 54.578 / trail 24.643）；设计位自洽锚（travel=0 精确返回设计 cam/toe）与镜像对称测试已入 `tests/test_w4_consistency.py`。注意方向：这次是引擎错、前端对——与第三讲 3.5 的转向轴裂缝（前端对、引擎错）一样，双实现互为审计器。

5.4 前视瞬心 IC 与侧倾中心 RC：构造 + 结账

📐 推导：三步构造（引擎 pose_metrics 的 rc_h 全过程）
Step 1 臂轴线插值到轮心站位

下臂轴线是 3D 直线（LCA_F→LCA_R），取它在 $y = wc_y$ 处的点（线性插值，第 2 章 lerp）；上臂同理。得到前视平面 (X-Z) 内的两个 pivot 点 $lp, up$。

Step 2 两直线求交 = 克莱姆法则

线 1：$lp + t\,(LBJ - lp)$；线 2：$up + s\,(UBJ - up)$。交点满足 2×2 线性方程组，解：

$$t = \frac{\mathrm{cross}(up - lp,\ d_2)}{\mathrm{cross}(d_1, d_2)}, \qquad \mathrm{cross}((a,b),(c,d)) = ad - bc$$

分母 = 两线方向叉积（平行四边形面积）= 0 时无交点（臂平行 ⟹ 瞬心在无穷远 ⟹ rc_h 返回 None，前端同理）。

Step 3 接地点→IC 连线交车中心面

侧倾中心的经典构造：直线 $cp \to IC$ 与中面 $x = 0$ 的交点高度。

$$t = \frac{0 - cp_x}{IC_x - cp_x}, \qquad \boxed{z_{RC} = cp_z + t\,(IC_z - cp_z)}$$

5.5 侧视瞬心（SVIC）与抗俯冲 / 抗下蹲（Anti-Dive / Anti-Squat）

📐 推导：侧视瞬心与制动抗俯冲几何百分比

在侧视平面（$Y-Z$ 平面）内，上下控制臂轴线的延长线交点即为侧视瞬心 $\mathrm{SVIC} = (y_{sv},\ z_{sv})$。车轮接地印迹中心为 $(y_{cp},\ z_{cp})$。

从接地点到侧视瞬心的连线与地面构成的俯冲几何角 $\theta_{\text{sv}}$ 满足：

$$\tan\theta_{\text{sv}} = \frac{z_{sv} - z_{cp}}{y_{cp} - y_{sv}}$$

设整车轴距为 $L$，质心高度为 $h_{cg}$，前轴制动力占整车总制动力的比例为 $k_b = F_{\text{brake}, f} / F_{\text{brake}, \text{total}}$。则前悬架的抗俯冲率（Anti-Dive %）为：

$$\text{Anti-Dive}\% = \frac{\tan\theta_{\text{sv}}}{\frac{h_{cg}}{L}} \times k_b \times 100\%$$

物理意义：当刹车制动力 $F_y$（纵向）作用于车轮时，通过悬架连杆倾角在转向节处产生向下的反拉力，部分抵消由整车惯性俯仰力矩带来的弹簧压缩。若 $\text{Anti-Dive} = 100\%$，则制动时前悬架弹簧无垂向压缩变形（纯几何力学平衡）——严格地说这只在忽略弹簧预载变化、轮胎下沉与衬套柔度时成立（理想几何近似；真实车 100% 抗俯冲会损失颠簸顺性，工程上常取 50% 左右）。

5.6 转向运动学与阿克曼转向几何（Ackermann %）

📐 推导：阿克曼转向几何百分比

赛车在低速转弯时，为了消除内外轮侧向滑移，理想状态下所有车轮的轴线延长线应当交于弯道旋转中心（即阿克曼几何）。设轮距为 $t_w$（沿 $X$ 轴），轴距为 $L$（沿 $Y$ 轴），内侧轮转角为 $\delta_i$，则纯阿克曼几何下的理论外侧轮转角 $\delta_{o, \text{ideal}}$ 满足：

$$\cot\delta_{o, \text{ideal}} - \cot\delta_i = \frac{t_w}{L} \implies \delta_{o, \text{ideal}} = \arctan\left(\frac{L}{\frac{L}{\tan\delta_i} + t_w}\right)$$

实际悬架由转向齿条拉杆驱动，实际外轮转角为 $\delta_o$。定义阿克曼百分比（Ackermann %）为：

$$\text{Ackermann}\% = \frac{\delta_i - \delta_o}{\delta_i - \delta_{o, \text{ideal}}} \times 100\%$$

调校直觉：$100\%$ 为纯阿克曼几何（低速顺畅）；$0\%$ 为平行转向（内外轮转角相同）；赛道上常采用反阿克曼转向（Ackermann < 0%），利用高速弯外侧轮承载大载荷、最佳侧偏角大的特性，提升整车极限弯道附着力。

5.7 从静态量到增益：扫掠 + 中心差分

📐 推导：中心差分的 $O(h^2)$ 精度（偶次项相消）

泰勒展开两式相减：

$$f(x+h) = f + f'h + \tfrac{f''}{2}h^2 + \tfrac{f'''}{6}h^3 + \cdots$$ $$f(x-h) = f - f'h + \tfrac{f''}{2}h^2 - \tfrac{f'''}{6}h^3 + \cdots$$

相减：偶次项（含 $f''$）全部抵消：

$$\frac{f(x+h) - f(x-h)}{2h} = f' + \frac{f'''}{6}h^2 + O(h^4)$$

误差 $O(h^2)$。引擎 metrics/kandc.py::_slope 采用最近邻采样点中央差分（取 $t{=}0$ 两侧最近的有效扫掠点做差商，None 跳过、端点单侧差分不虚高）——位移扫掠步长 5mm（±50mm/21 点）即实际 $h$，对光滑 K&C 曲线精度绰绰有余；F-10 修订后力轴（compliance）不再套用固定 ±2N 窗口，统一走同一内核。讲义第五讲钦定的 h=2mm 精神（局部性 vs 噪声折中）由"最近邻采样点"继承。

5.9 核心检查点与自测

Q1. 负外倾为什么 = 轮顶向内？用轴向量分量推一遍。

解析：右轮轴指 +X（外侧）；$\gamma<0 \Rightarrow a_z = -\sin\gamma > 0$，轴外端上翘；轮平面⊥轴，轴外端上翘 ⟹ 平面顶部倒向车内。弯道外侧轮被车身侧倾"扶正"，故静态负外倾 + 负外倾增益补偿。

Q2. 接地点为什么不在轮心正下方？偏移量公式？

解析：接地点沿轮平面内的竖直方向 $\hat r = \widehat{\hat z - a(\hat z \cdot a)}$（投影去掉轴向分量）。外倾时 $\hat z$ 不在轮平面内，$\hat r$ 向外倾侧偏 ⟹ 横向偏移 $= R\sin|\gamma|$，基线 6.81mm。

Q3. kg bug 的三步审计流程是什么？为什么 scrub=229 能被"量级直觉"直接怀疑？

解析：① 输出与物理直觉矛盾（负拖距配正后倾）；② 手算公式复现输出（确认输出即错而非显示错）；③ 对照第二实现（前端浏览器 54.5/+24.9）。量级直觉：磨胎半径量级 = 轮辋偏置级别（几十 mm），229mm 意味着转向时胎面大半径刮擦——FSAE 转向机会被撕裂。

Q4. isect2 的分母为零意味着什么几何？rc_h 返回 None 后前端怎么处理？

解析：两臂延长线平行 ⟹ 前视瞬心在无穷远 ⟹ cp→IC 连线趋向水平 ⟹ RC 趋向负无穷；代码返回 None，前端 sampleSweep 对 null 做邻段插值/回退（第 9 章侧倾耦合迭代里的 _interp_fb 同款回退设计）。

Q5.（动手）中心差分 h 的选择：扫掠步长 vs 曲线局部性，怎么权衡？

解析：曲线在 0 附近近线性，h 大与小差异小（三阶项小）；但 h 太大把非局部弯曲平均进来，h 太小则撞上求解器残差噪声（$10^{-13}$ 级，问题不大）。引擎 _slope 取最近邻采样点（实际步长 5mm），讲义 h=2mm 的"局部性 vs 噪声"权衡由采样密度继承——与第 4 章差分步长的权衡同构。
