8.0 这一章解决的物理问题

除重力和空气，赛车唯一的力源是四块巴掌大的胎面。悬架几何的全部意义，就是把这四个接触斑用到位（载荷分布、外倾、前束）。本章：① 滑移现象的物理（为什么"滚动的弹性体"能产生侧向力）；② Pacejka 魔术公式（MF）的 B/C/D/E 结构逐项解剖（每个字母控制曲线的什么）；③ 载荷敏感性与本子集的已知简化；④ 复合滑移与摩擦圆。

💡 直觉：刷子模型（tire as a brush）

把胎面想象成一排小刷毛粘在轮辋上。车轮指向与运动方向差一个角度 α（侧偏角）时：每根刷毛触地瞬间被"粘住"，轮辋继续前进，刷毛被剪切变形——弹性恢复力 = 侧向力。小 α：力 ∝ 变形 ∝ α（线性区，侧偏刚度）；α 增大：越来越多的刷毛达到摩擦极限开始滑移，力增长变缓；某个 α 达峰值 ≈ μ·Fz；再增大：滑动区占主导，力反而回落。纵向上同理：驱/制动让轮速 ≠ 车速（滑移率 κ），产生 Fx。MF 就是为这条"升起-峰值-回落"曲线设计的经验公式。

8.1 滑移量的定义

$$\alpha = (\text{车轮指向} - \text{速度方向}) \text{ 的夹角（°）}, \qquad \kappa = -\frac{v_{wheel} - \omega R}{|v|} \;(\text{滑移率，制动为正})$$

侧偏角是"几何角"，滑移率是"速度差的无量纲化"。两者都是滑移速度与滚动速度之比的不同投影——深层统一（Pacejka 理论的 ISO 滑移定义），本子集各用各的。

8.2 魔术公式逐项解剖

📐 公式与三个解析性质（零跳步）
$$Y(X) = D\,\sin\Big(C \arctan\big(\underbrace{B X - E\,(B X - \arctan B X)}_{\Theta}\big)\Big) + S_v, \quad X = \alpha + S_h$$
性质 1 零点斜率 = D·C·B（E 在原点不起作用）

链式求导：$\frac{dY}{dX} = D\cos(C\Phi) \cdot C \Phi'$，$\Phi = \arctan\Theta$。在 $X=0$：$\Theta = 0$，$\Phi = 0$，$\cos 0 = 1$；$\Theta' = B - E(B - B) = B$；$\Phi' = \Theta'/(1+\Theta^2) = B$。故

$$\frac{dY}{dX}\Big|_0 = D\,C\,B \quad (\text{N/rad}) \;——\textbf{侧偏刚度 cornering stiffness}$$
性质 2 峰值上界 = D

外层是 $D \sin(\cdot) \le D$；当内层幅角经过 $\pi/2$ 时取到 D（有限 X 处）。D 就是峰值摩擦力 $\mu F_z$ 的化身。

性质 3 渐近线 = D·sin(Cπ/2)

$X \to \infty$：$\Theta \to \infty$，$\Phi \to \pi/2$，$Y \to D\sin(C\pi/2)$。$C = 1.2 \Rightarrow \sin(108°) = 0.951$：完全滑动时力回落到峰值的 95%——C 决定峰后回落多少。

8.3 载荷与摩擦：D 的线性化及其代价

📐 本子集的载荷模型
$$D(F_z) = F_{y0} \cdot \frac{F_z}{F_{z,nom}} \;\Longrightarrow\; \mu_{eff}(F_z) = \frac{D}{F_z} = \frac{F_{y0}}{F_{z,nom}} = \text{常数（实测 2.2485 恒定）}$$
⚠️ 已知简化：载荷敏感性（load sensitivity）缺失

真实轮胎：$\mu$ 随 $F_z$ 递减（胎体非线性，重压下接触压强分布恶化）——经验式 $D \sim (a F_z + a_2 F_z^2)$ 带负二次项。本子集：D 线性 ⟹ μ 恒定（实验 2 实测 2.2485 全载荷不变）。

后果链（第 9/11 章的伏笔，现在埋下）：载荷转移把轴上一轮加到 $F_z + \Delta$、另一轮减到 $F_z - \Delta$，真实轮胎下两轮侧向力之和 $\sum F_y = f(F_z+\Delta) + f(F_z-\Delta) < 2f(F_z)$（凹函数性质，Jensen 不等式）；线性 μ 下两者相等——本模型会低估载荷转移的抓地力损失，也因此无法表达"TLLTD 偏轻载端更好"的经典结论。要模拟该效应：给 D 加负二次项（一处改动，OpenItem 级）。

8.4 复合滑移：摩擦圆与一个不一致观察

💡 摩擦椭圆（本项目的回退检查）

同一点上，可用摩擦在 Fx/Fy 之间分配：$\sqrt{(F_x/\mu_x F_z)^2 + (F_y/\mu_y F_z)^2} \le 1$。直觉：摩擦力是"预算"，驱动/制动花掉的预算不能再买侧向力——弯中给油推头、刹车入弯甩尾，都是圆被吃满的表象。完整 MF 联合模型（MF-Tyre 的复合滑移耦合）远比圆复杂；本项目用圆作为无 MF 参数时的回退。

⚠️ 观察：回退 μ 与 MF 默认值不一致（读码发现）

实验：MF 默认参数下 $F_x(\kappa{=}0.05) = 4614$N 已超过回退检查的 $\mu F_z = 0.9 \times 3500 = 3150$N——回退圆的 μ=0.9 硬编码，而 MF 默认参数实际描述的是 $\mu \approx 2.25$ 的胎（FSAE 赛事+下压力语境的合理值，但两者各说各话）。生产级一致性要求：回退 μ 应从 MF 参数推导（$F_{y0}/F_{z,nom}$）或由用户统一给定——登记为观察项。

8.5 回正力矩 Mz：占位实现与其物理

本项目 $M_z = 0.06\,F_y$（常数拖距 60mm，源码自标 APPROXIMATE）。真实物理： pneumatic trail $t(\alpha)$ 随侧偏增大递减（滑移区从后向前侵蚀接触斑，合力中心前移）——所以 Mz 的峰值比 Fy 的峰值来得早，越过之后回正力矩衰减甚至反号（手感变轻、丢方向的来源）。常数拖距丢掉了整段故事，但力矩量级正确。

8.7 核心检查点与自测

Q1. 用刷子模型解释：为什么 Fy-α 曲线有线性区、峰值、回落三段？

解析：小 α 刷毛粘附剪切，力 ∝ 变形（线性区，斜率=侧偏刚度）；α 大，滑移区从后缘扩张，达摩擦极限的刷毛不再增力（饱和弯曲）；全滑后摩擦力 ≈ μFz·滑动方向合力，α 再增大只是把滑动方向转向纯侧向的极限——结合回落段由 C>1 的 MF 形状刻画。

Q2. 推导零点斜率 = D·C·B。E 为什么在原点不出现？

解析：链式法则 + 原点处 Θ=0、Φ'=Θ'=B（E 项导数 (B−arctan BX)' 在 0 处 = B−B = 0，被 E 乘后消失）。E 只 reshape 峰附近。

Q3. 载荷转移让轴上两轮 ±ΔFz。真实轮胎与本模型各产生多少总侧向力差？工程含义？

解析：本模型 D 线性 ⟹ f(Fz+Δ)+f(Fz−Δ) = 2f(Fz)，转移无损失；真实 μ(Fz) 递减 ⟹ 凹函数 ⟹ 和下降（Jensen）。含义：真实车不应把一轴压死——TLLTD 偏轻载端/控制总转移量都是为此服务；本模型系统性乐观，比较设计相对优劣仍有效，绝对圈速预测失真。

Q4. RWD 赛车弯中猛给油为什么趋向甩尾（过度）？带刹入弯为什么趋向推头？用摩擦圆各解释一遍。

解析：摩擦圆语言 = "Fx 占用谁的圆，谁先丢 Fy"。给油：驱动 Fx 全部记在后轮账上 → 后轮圆预算被 Fx 吃掉 → 可用 Fy 下降 → 车尾先丢侧向力 = 过度（power oversteer）。带刹：制动力主要压在前轮（+载荷前移让前轮 Fz 大、制动力配额大）→ 前轮圆被 Fx 占用 → 前轮 Fy 先掉 = 推头（brake understeer）。同一物理，两种症状，取决于 Fx 记在哪个轴的账上。

Q5.（动手）把 By 改 12（更硬的胎侧），零点斜率与峰位怎么变？跑一下验证你的预测。

解析：斜率 = D·C·B → ×12/9 = 1508×1.333 ≈ 2011 N/°；峰位提前（更快到达饱和，类比 C 实验的 8.3° 方向）。峰值仍 ≈ D（8000）。"更硬的胎"= 更快建立力 = 响应更快但滑移窗口更窄。
