6.0 这一章解决的物理问题

垂向弹性路径（第一讲的 6 环节链）里藏着一个变换器：推杆→摇臂→减振器把轮端的行程与力按杠杆比变换后交给弹簧。这个比叫运动速比 MR（Motion Ratio），它决定轮端刚度、侧倾刚度、以及所有以"轮端"计价的力学量。本章：① 从能量守恒推出 $k_w = k_S \cdot mr^2$；② 讲清摇臂从动链的求解模型（2026-08-22 P2 后为三维轴 Rodrigues）；③ 解剖引擎摇臂的三大历史病例（分支跳变 + 压缩侧无解 + MR=0——P0 时 kw_curve 必须由前端下发的原因，修复后的现状见各病例标注）；④ 推导防倾杆扭转刚度全链 $J \to GJ/L \to k_\phi$。

6.1 运动速比：$k_w = k_S \, mr^2$ 从能量守恒推出来

📐 推导（零跳步）
定义 MR = 减振器行程变化率 / 轮跳变化率
$$mr = \left|\frac{dL_{damper}}{d\,travel}\right| \quad \text{（无量纲；前端/引擎都用中心差分数值导数）}$$
Step 1 无功传递（理想杆件不储能）

轮端输入功 = 弹簧吸收功：$F_w\,\delta_w = F_S\,\delta_S$。

Step 2 位移比与力比互为倒数
$$\frac{F_w}{F_S} = \frac{\delta_S}{\delta_w} = mr$$
Step 3 刚度按平方变换
$$k_w = \frac{dF_w}{d\delta_w} = \frac{d(F_S\,mr)}{d\delta_w} = k_S\,mr \cdot \frac{d\delta_S}{d\delta_w} = k_S\,mr^2$$

数值感：$mr = 0.75 \Rightarrow k_w = 0.5625\,k_S$——110 N/mm 的弹簧到轮端只剩 62 N/mm。平方惩罚是推杆/拉杆架构的定价：省了空间（减振器可横置低位），付出刚度与阻尼效率。

6.2 摇臂从动链：为什么不在第 3 章的 $F(x)$ 里

💡 DOF 论证（第 3 章方法论的直接应用）

轮侧 18 坐标解完后，传动链剩一个未知量：摇臂转角 $\theta$。约束也只剩一条：推杆定长 $\|R(\theta; CH5_0) - UP4\| = L_{pr}$——1 未知 1 方程，且轮侧解不依赖 $\theta$（推杆从动）。所以它是后处理而非联立对象：解 $\theta$ 后刚体旋转带上 RCK_DMP，减振器长度随之确定。这是"删自由度"思想的镜像：不是删不关心的，而是解耦可后置的。

🎯 引擎模型：空间三维轴 Rodrigues + 二分求根（2026-08-22 P2 修复后）
  • 三维轴（P2 修复）：solve_rocker 绕 RCK_AX_A→RCK_AX_B 确定的真实三维轴做 Rodrigues 旋转（第 2 章公式）——取代旧实现的"绕全局 X 轴/固定 $x$ 平面"假设。历史痛点：旧 rotate_around_x 把摇臂端锁死在 $x = CH5_0.x$ 平面内，与真实轴几何不符（$\Delta x{=}359$mm 不可吸收），是下方大案（压缩侧无解、MR 垃圾值）的根因。
  • 求根：$err(\theta) = \|\text{Rodrigues}(\theta) - UP4\| - L_{pr}$，先在 $(0, \pm0.05, \pm0.2, \dots, \pm3.1)$ 里找符号变化括住区间，再二分 60 次（F-71 优化：缓存 $err(lo)$ 不重复计算）。
  • 成功才写回：失败时 CH5/RK_DAMPER 留在设计位——下方大案的历史第一现场（修复前）。

6.3 ⚠️ 大案：引擎摇臂病理解剖（P0 决策的机构级解释；2026-08-22 P2 已修复）

⚠️ 病例一（历史·修复前）：压缩 ≥ +5mm 彻底无解（工作空间边界）

⚠️ 病例三（历史·修复前）：MR = 0 的完整因果链（P0 之谜的答案）
  1. 压缩 ≥+5mm 无根（旧平面圆模型）→ solve_rocker 失败；
  2. 失败不写回 → RK_DAMPER 冻在设计位；
  3. damper 长度 = 常数 289.5 → 中心差分 $mr = 0$（P0 实测压缩侧 mr≈0 甚至变号，根因在此）；
  4. 回弹侧因分支跳变，damper 曲线非单调 → ±2mm 微分出垃圾值（S2-5 实测 3.98 vs 前端 0.75）。

为什么前端没事：projRockerStrut 用闭式解（余弦定理 + 分支规则，连续）且其机构拓扑不同（STRUT_OUT 挂在铰链簇上，UP4 的运动远离工作空间边界）——damper 曲线良好，$mr \approx 0.75$。P0 的架构决策由此获得机构级依据：引擎 kw 迁移不可自算 → KwCurve 由前端下发。

修复后（2026-08-22 P2 + 2026-08-30 收尾）：引擎摇臂改三维轴 Rodrigues 后，mr_at_zero 数值推导恢复可信，进入 MR 三路优先级的第二档（显式 > 推导 > 分轴常量回退）；回退常量也按轴分开（前 0.75/后 0.78，F-67），推导失败不再静默吞异常。残余分支差异登记 OpenItem-B（见故意不同清单）。

📐 正向建模方案：空间任意轴 3D 摇臂（Rodrigues + 求根，与引擎实现对应）

为根治 2D 平面旋转造成的边界无解与求根跳变，修复后的引擎采用三维空间任意轴 Rodrigues 旋转公式（第 2 章 2.4 的直接应用）：

设摇臂旋转轴线由空间单位向量 $\hat{\mathbf{n}}$ 与枢轴点 $P_{\text{pivot}}$ 确定，推杆在摇臂上的铰接点初始位置为 $P_0$。转动 $\theta$ 后的空间坐标为：

$$P(\theta) = P_{\text{pivot}} + \cos\theta\,(P_0 - P_{\text{pivot}}) + (\hat{\mathbf{n}} \times (P_0 - P_{\text{pivot}}))\sin\theta + \hat{\mathbf{n}}(\hat{\mathbf{n}} \cdot (P_0 - P_{\text{pivot}}))(1 - \cos\theta)$$

推杆定长约束 $\|P(\theta) - \mathrm{UP4}\|^2 = L_{pr}^2$ 展开后精确化为关于 $\theta$ 的标准三角方程：

$$A\cos\theta + B\sin\theta = C$$

两种求根（引擎实测选二分）：① 引擎 solve_rocker 用 bracket 括根 + 60 次二分（6.2，对连续单调段无条件稳定）；② 若引入万能代换 $t = \tan(\theta/2)$，方程转化为一元二次代数方程：$(C+A)t^2 - 2Bt + (C-A) = 0$，选取与物理装配构型一致的符号分支即可闭式解出——微秒级、无迭代。引擎当前用 ① 并登记 ② 为等价备选；两者的共同前提都是真实的 $\hat{\mathbf{n}}$ 三维轴（这正是修复的核心，平面假设被消除）。

6.4 防倾杆：从圆截面到侧倾刚度的全链推导

📐 推导：四级链条（零跳步）
Step 1 圆截面极惯性矩 $J$（面积分）
$$J = \int_A r^2\,dA = \int_0^{R} r^2 \cdot 2\pi r\,dr = 2\pi \frac{R^4}{4} = \frac{\pi R^4}{2} = \frac{\pi d^4}{32}$$

$d = 18$mm ⟹ $J = 10\,306$ mm⁴。四次方敏感性：直径 +22%（18→22）刚度 +123%——调 ARB 先调直径。

Step 2 扭转刚度 $k_t = GJ/L$

等直圆杆扭转：截面剪应变 $\gamma(r) = r\,\varphi/L$（$\varphi$ 为总扭角），剪应力 $\tau = G\gamma$，扭矩 $T = \int \tau r\, dA = \frac{G\varphi}{L} J$ ⟹：

$$k_t = \frac{T}{\varphi} = \frac{GJ}{L} = \frac{79\,000 \times 10\,306}{1019} = 798\,993\ \text{N·mm/rad}$$

$L = 2 x_a = 2 \times 509.5$（有效扭臂段 = 两立柱间距，圆轴横穿车身）。

Step 3 立柱端的线刚度

立柱臂长 $a = 143.5$mm：端部力 $F$ 产生扭矩 $T = F a$，端部位移 $s = a\varphi = a T / k_t$ ⟹

$$k_{end} = \frac{F}{s} = \frac{k_t}{a^2} = 38.8\ \text{N/mm（单端固定式定义）}$$

再到轮端（ARB 连杆挂在 LCA 的 $t=0.55$ 位置比 + 传动效率，引擎统一记 $mr_{arb} = 0.55$）：

$$k = k_{end} \cdot mr_{arb}^2 = 11.74\ \text{N/mm（轮端计价）}$$
Step 4 侧倾刚度贡献（与第 1 讲的 ½ 同构）
$$k_{\phi,arb} = k \times 10^3 \times \frac{t_f^2}{2} = 11.74 \times 1000 \times \frac{1.620^2}{2} = 15\,402\ \text{N·m/rad}$$

对照弹簧侧 $k_\phi = \tfrac12 k_w t_f^2 = 81\,192$ ⟹ ARB 占前轴侧倾刚度 15.9%——与端到端 HTTP 输出的 arb_share_f 同链自洽（同一公式链，非独立互证；该比例是参数恒量，与载荷/工况无关）。

⚠️ 诚实标注：$mr_{arb} = 0.55$ 是校准包袱

按单端固定定义 $k_{end}$ 严格推侧倾响应，系数应为 $k\,t^2$ 而非 $k\,t^2/2$（两端反对称运动时有效扭转是单端固定的两倍）。代码的 $\tfrac12$ 与 $mr_{arb}$ 把"连杆位置比、传动效率、端部定义"全部打包校准——前后端共用同一约定（数值自洽），但绝对值携带模型不确定性。工程结论：ARB 的相对比较（直径 18→22、前后平衡调整）可信；绝对侧倾刚度贡献若要精确，需拆开端部运动学重新标定。区分"结构性公式"与"校准常数"是读工业代码的关键素养。

6.6 核心检查点与自测

Q1. 为什么 $k_w = k_S mr^2$ 是平方而不是一次方？

解析：力按 $mr$ 放大（杠杆），位移按 $1/mr$ 缩小（同一功的两次记账）；刚度 = 力/位移，两个 $mr$ 相乘。等价地：$k_w = dF_w/d\delta_w$，$F_w = mr F_S$，$\delta_S = mr\,\delta_w$，链式法则展开即得。

Q2. 摇臂为什么可以后置求解而不进第 3 章的 $F(x)$？

解析：DOF 论证——轮侧 18 坐标 + 双驱动已恰定；摇臂角是唯一剩余未知且只有一条约束（推杆定长），且轮侧约束不含 $\theta$（推杆从动）⟹ 单未知单方程后处理。这是"删/解耦不关心自由度"思想的应用：不联立能解耦的部分。

Q3. 引擎 MR=0 的完整因果链？（四步，历史案例）

解析：压缩 ≥+5mm 平面圆无可达根（推杆近径向张直，工作空间边界——旧平面模型）→ solve_rocker 失败不写回 → RK_DAMPER 冻结设计位 → damper 常数 → 中心差分 mr=0；回弹侧另有分支跳变污染。已修复：2026-08-22 P2 摇臂改真实三维轴 Rodrigues 后无解带消除；2026-08-30 让 mr_at_zero 数值推导恢复为 MR 三路的第二档（显式 > 推导 > 分轴常量回退 0.75/0.78）。做题时把它当"病理解剖的教科书案例"而非现状。

Q4. ARB 直径 18→22mm，$k_\phi$ 变多少？为什么调杆先调直径？

解析：$J \propto d^4$ ⟹ $(22/18)^4 = 2.23$ 倍（+123%）。四次方敏感性让直径成为最有效的调节旋钮；连杆位置比 $t$ 只影响 $mr_{arb}$（平方项、范围有限）。

Q5.（动手）用 6.3 的法医公式算：把 RCK_DMP 的 z 提高 20mm，工作空间边界移到哪个 travel？

解析：边界条件 $r_{arm} + \rho(UP4) = d_{yz}^{need}$。改 RCK_DMP 不改 $r_{arm}$（那是 CH5 的圆）也不改 $\rho(UP4)$——陷阱！真正动边界的是枢轴 RCK_AX 位置（改 $r_{arm}$ 与 $\Delta x$）或 CH5/STRUT_IN（改 $d_{yz}^{need}$）。做错这题说明把摇臂端圆和减振器端搞混了——圆是 CH5 画的，RCK_DMP 只是被 $\theta$ 刚体带动读数。注：本推算基于 6.3 的旧平面圆模型（历史几何）；三维轴修复后边界由真实轴方向与 $CH5{\to}UP4$ 空间距离决定，"改谁更有效"的结论近似成立、精确判定交给求根实验。
