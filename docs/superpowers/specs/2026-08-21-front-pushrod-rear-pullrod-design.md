# 前推杆 / 后拉杆 双叉臂悬架正式构建（dwb-mod）· 设计

日期：2026-08-21
载体：`dwb-mod/double-wishbone-suspension.html`（独立魔改版仿真台，无后端）
状态：设计已获用户批准（2026-08-21），本文档为实施依据

## 1. 背景与需求

用户在上一轮（开放 bug 修复：首帧 TypeError 卡死 + PROD 前推后拉收敛性）验收后，
提出正式构建「前推杆（Front Pushrod）+ 后拉杆（Rear Pullrod）双叉臂」悬架：

- 前悬：双叉臂 + 推杆从下叉臂外端以 ~45° 上斜接入高位摇臂；摇臂装于底盘上纵梁；
  摇臂另端连接**水平纵置**的圈状减振器（横躺于底盘顶部）。
- 后悬：双叉臂 + 拉杆从上叉臂外端陡下斜接入低位摇臂；摇臂装于齿轮箱底部；
  连接**贴近地板水平纵置**的圈状减振器。
- A 臂采用气动泪滴形截面；推杆/拉杆为圆柱杆 + 端部 Heim 关节；
  转向节含中央轮毂轴承孔。
- 配色：碳纤黑（叉臂/连杆）、钛银（摇臂）、Ohlins 金黄（弹簧）。
- 整车：轴距 3000mm，轮距 1600mm。
- **不要局限于现有节点数量**：允许新增硬点/节点。

用户裁定：
- 实现载体 = 重构 `dwb-mod/double-wishbone-suspension.html`（保留 2D 四视图 + 运动学/动力学仿真）。
- 范围 = 几何拓扑 + 渲染 + 求解器**全量适配**（运动学联动继续可用）。
- 坐标系沿用文件现有约定（见 §2），用户规格中的 X 纵向仅作总布置描述。

## 2. 坐标系与总布置

沿用文件约定：**X=外侧（右轮为正）、Y=车头方向（正）、Z=向上，原点=前轴中心地面**。
「前」=Y+，「后」=Y−。用户规格（X 纵向前后 / Y 横向 / Z 上）与本约定映射：前=Y+、横向=X。

- 轴距 3000mm → 后轴整体位于 Y=−1500。
- 轮距 1600mm → 前/后轴轮心 X=±800（本侧按 X=+800 建模，镜像出 X=−800）。
- 轮胎 245/40R17（R=318mm），轮心 Z=318，设计地面 Z=0（接地点=Z 0）。
- 摇臂轴始终沿车架 X（横向），与既有 `projHinge` 单点枢轴默认 X 轴一致。

| WC | 轮心 | knuckle | 驱动点（轮跳） |
| TRO / RACK | 转向臂外点 / 齿条内点 | knuckle / chassis | 横拉杆，仅前轴施加 rack |

质量：PR_L 0.6kg、PR_U 0.6kg、RK_B 0.005kg（沿用上轮收敛性结论）、RK_A 0kg。

### 3.2 链路（LINKDEF 扩展）

新增刚性线（按节点存在性注册）：
- 推杆：`PR_L ↔ RK_B`（前轴）
- 拉杆：`PR_U ↔ RK_B`（后轴）

现有链路不变（LCA/UCA 叉臂网、主销、转向节网、横拉杆）。
弹性线（弹簧+减振器）：`RK_A ↔ DMP_T`（两轴，水平）。`SPR_L` 节点保留但不再参与弹性线。

### 3.3 刚体簇

- `hinge LCA`：members = [LBJ, SPR_L, **PR_L（若存在）**] — 绕 LCA_F-LCA_R 轴
- `hinge UCA`：members = [UBJ, **PR_U（若存在）**] — 绕 UCA_F-UCA_R 轴
- `body KNUCKLE`：members = [LBJ, UBJ, WC, TRO]
- `hinge ROCKER`：members = [RK_A, RK_B]，枢轴=RK_PIVOT（axA==axB → 默认 X 轴，上轮已修复）

### 3.4 前后轴显式分支（替代现有"离谁近猜推拉"）

`addPushrodMode` 改为按 `M.axleKey` 显式声明：
- front：rod = PR_L→RK_B（推杆），damper 弹性线 RK_A(高位)→DMP_T(高位水平)
- rear：rod = PR_U→RK_B（拉杆），damper 弹性线 RK_A(低位)→DMP_T(低位水平)
- 若该轴缺少对应节点（旧存档/旧预设）→ 整体跳过推杆模式，退回纯叉臂+弹簧（兼容）

## 5. 求解器适配

- `buildMech`：LCA/UCA 簇 members 按节点存在性组装；`nCons`/`nFree`/`dof` 自动更新。
- `sweepProj`：保留上轮机制 —— 摇臂+推/拉杆局部回路 K=12 内迭代、RK_B 轻质量双向分配、
  单点枢轴默认 X 轴。新几何不做算法改动，仅数据驱动（除非回归暴露新问题）。
- `setChassis`：PR_L/PR_U 为自由节点不涉及；RK_PIVOT/DMP_T 固定节点按轴数据写入。
- `driveTo`/`findLimits`/`runSweep`：无需改动。
- **回归验收**：fresh/存档 PROD/存后轴/新 FSR-06 四场景，300 帧零异常；
  前后轴 findLimits ≥ ±60mm；轮跳满幅正弦；残差达标。

## 6. 指标适配

- `metrics.sl`（弹簧-减振器长度）：由 `dst(SPR_L, DMP_T)` 改为 `dst(M.spring.a, M.spring.b)`
  （即 RK_A↔DMP_T），运动速比/轮心刚度/簧载频率随之正确。
- 其余指标（camber/toe/caster/KPI/scrub/trail/IC/RC/anti）不动，仍由 WC/LBJ/UBJ/TRO 计算。

## 7. 渲染升级（仅视觉，不改仿真）

- **A 臂泪滴截面**：新增泪滴多边形生成器（给定两端点、中宽、钝头半径、尖收率）：
  叉臂杆从单线改为泪滴轮廓（球头端圆钝、铰端收尖）+ 半透明碳纤黑填充 `C.carbon #1f2429` +
  轮廓线；两臂（前/后支杆）分别生成。
- **摇臂**：枢轴→RK_A/RK_B 两臂多边形 + 钛银 `C.rocker #b9c2c9` 填充。
- **推杆/拉杆**：圆柱（cylinder 已有）+ 粗线 + 两端 Heim 球头（circPts 球，径 12）。
- **水平减振器**：`springPts`/cylinder 沿 RK_A→DMP_T 自动水平；弹簧金黄沿用 `C.ela #d9a238`
  （= Ohlins 金）；两端弹簧座 + 筒身（现有逻辑复用）。
- **底盘水平支架**（addShared 减振器塔改造）：按轴数据画水平支托 —— 前轴高位（Z≈600）、
  后轴低位（Z≈110），替代现垂直塔；支承两端。
- 转向节中央轮毂轴承孔：制动盘 hub 圆柱加深色内圈示意（小改）。
- 球头（LBJ/UBJ/TRO）与 Heim 关节继续用现有球头画法。

## 8. 预设与兼容

- 新增默认预设 **「FSR-06 前推后拉正式版」**：轴距 3000、轮距 1600、cam0 −3.0°、toe0 +0.05°、
  mS 300kg、kS 95N/mm、cB 8、cR 12、kT 240；含全部 16 节点（前后轴独立数据）。
- 旧 4 预设（SPORT/RACE/SUV/PROD）保留：PROD 用新拓扑重写（显式推/拉杆数据），
  rearRk 猜测机制删除。
- 兼容：无 PR_* 节点的旧预设/旧存档 → 推杆模式自动跳过、硬点表对应行禁用（上轮已实现），不崩溃。
- S.axles.rear.hp 仍由前轴平移生成 + 后轴 override 表（RK_*/PR_U/DMP_T 等差异点）。

## 9. 验收标准

1. 新预设打开即动：轮跳正弦满幅（±52mm 内），四视图正确显示前推后拉拓扑。
2. 前后轴 findLimits ≥ ±60mm（几何工作段），残差 <0.02mm，M.ok=true。
3. 拖拽/表格编辑 PR_L/PR_U/RK_*/DMP_T 即时生效并持久化。
4. 台架动力学模式（RIG）下弹簧/阻尼/轮胎力正常（弹性线端点已改）。
5. 旧预设/旧存档打开不崩（回归 harness 四场景 300 帧零异常）。
6. 渲染：泪滴臂、钛银摇臂、金色弹簧、水平减振器、Heim 关节肉眼可辨。
