# DWB 全底盘改造（整车运动学工具台）设计规格

> 日期：2026-08-21
> 对象：`double-wishbone-suspension.html`（DWB-SIM，2104 行单文件）直接增长式改造，不推倒重写。
> 用户决策记录：Part1（架构与建模层）+ Part2（分析层/持久化/交互/验收）已批准；**前后轴解耦**为本规格硬约束。

---

## 1. 目标（一句话）

把 DWB-SIM 从"单前轴仿真台"扩展为"**前+后轴四轮同屏、硬点可拖可存、整车运动学可分析**"的全底盘工具台；以参考既有建模细节为标准，修正立柱（主销）、减震弹簧连接、转向 toe in/out 视觉三处；保持单文件双击即开与 DWB 式交互丝滑。

## 2. 硬约束（用户拍板）

- **前后轴解耦**：四个角落的机构各自独立求解；**不建立车架刚体耦合、不跨轴传递运动与力**。"整车侧倾角/俯仰角"仅作为**输入映射**（侧倾→各轴左右差动行程；俯仰→前/后轴分组差动行程），"整车侧倾轴线/轴距变化"仅作为**几何读数综合**（前后轴 RC 连线的静态几何），无动力学含义。
- 本轮**不做**：四轮 7-DOF 台架动力学（下一轮）、后端桥接、生产 modeler 迁移、推杆摇臂拓扑（由用户日后拖节点+保存自行调出）。

## 3. 架构（增长式，沿用单文件分区基因）

### 3.1 四角机构
- 现有 `SIM.R / SIM.L`（前轴左右）升级为 `SIM.C = {fr, fl, rr, rl}`：四个**同构拓扑**机构，每角独立求解与镜像；
  - `buildMech()` 参数化 → `buildMech(axleKey, sideKey)`：同一工厂函数，前后轴各自一套硬点；左轮沿用"右侧模板镜像"生成（DWB 镜像哲学，**前后轴独立镜像**：拖后轴只影响后轴）。
- 后轴转角细节：后轴无转向（横拉杆刚性、rack 恒 0），主销/外倾/前束/拖距读数照常。

### 3.2 整车状态
- `S.axles = { front: {hp, tire, wb...}, rear: {...} }`；`S.axleView: "all" | "front" | "rear"`（顶栏按钮 + 键盘快捷键）。
- 全局：轴距 `wb`（编辑，默认 2450mm）、整车侧倾角输入、整车俯仰角输入、四轮独立轮跳（fr/fl/rr/rl）。

### 3.3 整车坐标布置（沿用 DWB 本地坐标，保持一致）
- X 横向（右+）、Y 车头（+）、Z 上；原点 = 前轴中心地面；
- **后轴按 `wb` 布置在 Y ≈ −wb**（前后轴轮距各自独立可编辑）；俯视图直接可见前后轴相对关系。

## 4. 建模细节修正（本轮重点，用户点名）

1. **立柱（主销）**：逐帧核对几何层转向节刚体绕真实主销轴线（上下球头连线）旋转；渲染层车轮自旋轴 `ax` 随转向节更新——**修复任何"转向时轮子不绕主销转"的残余**；toe in/out 真实转角同时进读数与视觉（俯视图前束弧 + 车轮朝向）。
2. **减震弹簧连接**：弹簧/减振器两端严格接真实节点（摆臂 SPR ↔ 车架塔 DMP_T）；四轴统一；修复"弹簧不跟机构"残留。
3. **转向机制**：前轴齿条驱动（FL1 沿齿条轴平移 → 横拉杆 → 转向节绕主销），保持 DWB 现有链路正确性；后轴 rack 恒 0。

## 5. 整车分析层（本轮能力）

### 输入
- 保留：travel / roll / rack / 跳动激励 / 转向激励（作用于前轴；roll 作用于两轴左右差动）；
- 新增：四轮独立轮跳滑块（fr/fl/rr/rl）、整车侧倾角（**映射公式：各轴左右行程差 = 该轴半轮距·tan(roll)**，沿用 DWB rollOffset 逻辑分轴应用）、整车俯仰角（**映射公式：前轴组 +Δ、后轴组 −Δ，Δ 可编辑**）、轴距 `wb` 编辑。

### 读数（右栏分组）
- **每轮定位角**（四轮同表）：camber / toe / caster / KPI / scrub / trail / included angle；
- **每轴**：速比、外倾增益°/25、跳动转向°/25、行程极限、正视瞬心、单轴侧倾中心；
- **整车（几何综合）**：前后轴 RC + 整车侧倾轴线（RC 连线视角）、抗俯仰(前)/抗蹲(后)、整车轴距/轮距变化、四轮接地点；
- **求解健康**：四轮残差 / 迭代 / 耗时一栏（顶栏或右栏）。

### 曲线（随工况）
- 前/后轴切换：外倾/前束/RC/速比/SCRUB 随轮跳（复用现有曲线面板 + 轴开关）；
- 新增整车曲线：整车侧倾中心高随（整车侧倾角输入）、整车轴距变化随（前轴+后轴同向）轮跳、前后轴 camber 对比。

## 6. 持久化与工作流

- **localStorage 自动保存**（前后轴硬点/轮胎/整车参数/当前轴视图）；打开即恢复；失败（file:// 受限）时静默降级并提示用 JSON 文件。
- **JSON 导出/导入**（下载/上传文件，自包含）：`{meta, front:{hp,tire}, rear:{hp,tire}, vehicle:{wb, kS...}}`；导入时校验结构。
- 预设：三预设（SPORT/RACE/SUV）保留为"整车示例"——**后轴示例 = 前轴几何平移至 Y=−wb**（诚实示例，用户自调）；新增按钮行【恢复示例 / 导出整车 JSON / 导入整车 JSON】。
- 节点拖拽即时生效：左右镜像、前后轴独立。

## 7. 交互与性能

- 四轮同框图元量约 ×2：沿用 130ms 扫掠节流 / 暂停不重绘 / 场景缓存；目标拖动 60fps，**实测为准**（超预算则降级：轴开关默认关对侧、或降低轮圈段数）。
- 轴开关联动"F 适应"与快捷键；键盘保持 空格/方向键/F/1-4/0；方向键轮跳作用于"当前轴视图对应侧"。

## 8. 验收清单（浏览器实测，逐项打勾）

1. 四轮同框 + 轴开关（all/front/rear）正确；
2. 拖后轴节点只改后轴；保存后刷新仍在；
3. 转向时前轮 toe in/out 视觉+读数正确、后轮不动；
4. 曲线随整车工况常驻 + 游标移动正确；
5. 四轮全行程残差 ≤ 0.02mm（各轮读数栏），无 console error；
6. 预设 / JSON 导出 / 导入往返一致（导出→导入→数值不变）；
7. 拖动不卡顿（肉眼 60fps 目标）；
8. 前后轴解耦验证：只给后轴轮跳，前轴读数不变（反之亦然）。

## 9. 实施开放项（实现时核对，非阻塞）

- `file://` 下 localStorage 在 Edge/Chrome 的行为差异（自动保存失败→JSON 兜底提示）；
- 预设"后轴=前轴平移"的轴距一致性（wb 与硬点默认值同步）；
- 性能实测点位：四轮同框最坏帧（全显示层开）的扫掠节流参数；
- 右栏面板布局：现有 300px 宽度能否容纳四轮同表（必要时加横向滚动或轴切换列）；
- 曲线面板 5 条上限 → 整车曲线入口的组织（复用右栏现有曲线区，加整车曲线子标签）。
