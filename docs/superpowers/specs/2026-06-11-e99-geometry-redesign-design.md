# E99 几何大修 — 设计文档

> 日期：2026-06-11 | 状态：设计中 | 备份：src/config_backup_20260611.py
> 目标：将现有 FSAE 悬架分析模型的整车几何对齐 RWTH Aachen E99 赛车参考图

## 目标与范围

**核心目标：** 用参考图（轴侧/侧视/俯视/前视四张）校准现有参数化模型，让生成的 3D 几何在形态、比例、姿态上贴合 E99。

**范围：** 全系统大修
- §1 基础尺寸 + 悬架硬点
- §2 车架节点 + 管路
- §3 空力套件（前翼/后翼/底板/扩散器）
- §4 车身覆盖件（25+ 新控制点）

**执行策略：** 一步到位，一次性改完 `src/config.py`，启动后直接看效果。
**备份：** `src/config_backup_20260611.py`

## §4 车身覆盖件 — 25+ 新控制点

E99 车身曲面复杂（鼻锥弧线、沙漏形侧箱、引擎盖隆起），需要大量新控制点。

### 4.1 鼻锥加密（5 点）
```
BODY_NOSE_TIP    [420, 0,    55]   # 鼻锥最尖点
BODY_NOSE_SIDE_R [380, 60,   95]   # 鼻锥右侧
BODY_NOSE_SIDE_L [380,-60,   95]   # 鼻锥左侧
BODY_NOSE_FRONT_R[340, 80,  110]   # 前缘右侧
BODY_NOSE_FRONT_L[340,-80,  110]   # 前缘左侧
```

### 4.2 前翼过渡（4 点）
```
BODY_FW_FAIR_R [200, 200,  85]    # 鼻锥到右前翼端板过渡
BODY_FW_FAIR_L [200,-200,  85]    # 鼻锥到左前翼端板过渡
BODY_FW_EDGE_R [250, 330,  50]    # 右前翼端板
BODY_FW_EDGE_L [250,-330,  50]    # 左前翼端板
```

### 4.3 侧箱主控点 — 沙漏形（6 点）
```
# 前段（前环后到中段最窄）
BODY_SIDE_FR_R [-50,  350, 165]   # 沙漏前段上沿
BODY_SIDE_FR_L [-50, -350, 165]
# 中段（驾驶员位置最窄）
BODY_SIDE_MR_R [-450, 320, 160]   # 沙漏中段上沿
BODY_SIDE_MR_L [-450,-320, 160]
# 后段（主环后向外扩张）
BODY_SIDE_RR_R [-850, 360, 175]   # 沙漏后段上沿
BODY_SIDE_RR_L [-850,-360, 175]
```

### 4.4 侧箱下沿（4 点）
```
BODY_SIDE_LWR_FR_R [-50,  310, 60]
BODY_SIDE_LWR_FR_L [-50, -310, 60]
BODY_SIDE_LWR_RR_R [-850, 320, 68]
BODY_SIDE_LWR_RR_L [-850,-320, 68]
```

### 4.5 引擎盖/驾驶舱后（4 点）
```
BODY_ENG_NECK_R [-700,  160, 305]   # 主环后到引擎盖过渡
BODY_ENG_NECK_L [-700, -160, 305]
BODY_ENG_BACK_R [-1100, 150, 280]   # 引擎盖后缘
BODY_ENG_BACK_L [-1100,-150, 280]
```

### 4.6 尾翼过渡（3 点）
```
BODY_RW_SIDE_R [-1100, 320, 410]    # 尾翼端板到车身右侧
BODY_RW_SIDE_L [-1100,-320, 410]    # 尾翼端板到车身左侧
BODY_RW_UNDER  [-1100,   0, 385]    # 尾翼下方
```

## §6 验证标准

- 3D 视口中：前轮距视觉上 ~830-840mm（占视野的合适比例）
- 侧视图：鼻锥贴地、主环高耸、翼面层次清晰
- 俯视图：沙漏形侧箱轮廓明显、A 臂角度自然
- 前视图：前翼展宽超出车体、端板包覆到位
- 运动学：拖动轮跳滑块，camber/toe 数值变化平滑，A 臂不穿模
