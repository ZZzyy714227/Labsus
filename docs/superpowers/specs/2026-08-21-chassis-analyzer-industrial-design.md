> **面向整车底盘与悬架开发全流程的工业级准静态 + 弹性动力学（K&C）+ 台架/整车动态分析软件**

## 2. 核心求解器能力（第一维度）

### 2.1 准静态运动学子系统（现有资产升级）

| 能力 | 实现 | 现状→目标 |
|---|---|---|
| 无奇异点 | 四元数 + 闭式极分解（Müller 迭代）+ 摇臂两点轴全局相角映射 | 已具备，成为**设计证明项**（极大行程/大转角不发散） |
| 投影扫描 | 铰链簇/刚体簇/距离/驱动四类投影交替；Continuation 分步 | 已具备，移植为纯 Python 服务 |
| 精度 | 几何残差 ≤ 0.02mm（正常态） | 机制求解器已达 1e-11，保留双轨（投影交互 / least_squares 校验） |
| 双驱动 | 四轮轮跳 + 齿条/转向输入统一状态 | 已具备（v2 机制求解器 DOF=2） |

### 2.2 K&C 弹性运动学（第一分水岭，本方案核心增量）

真实悬架含橡胶衬套——纯几何运动学只是基线。K&C 层设计：

- **衬套元件**：6 DOF 力-位移-速度关系
  - 对角刚度矩阵 k(δ)，每自由度可非线性曲线（样条插值）；可选耦合项矩阵
  - 阻尼 c(v) 速度相关；预紧/不对称刚度支持
- **求解结构**：两层迭代
  - 外循环（力平衡）：Newton-Raphson 于衬套形变向量 δ（残差 = 节点合力）
  - 内循环（机构投影）：当前衬套形变下的刚体几何投影求解
  - 收敛判据：几何残差 ≤0.02mm 且 力平衡残差 ≤1N / 0.1% 载荷（取宽）
- **输出**：衬套形变矢量（可视化）、由形变导出的 Toe/Camber 变化（Compliance Toe/Steer）、衬套载荷（6DOF）
- **工况**：纵向力、侧向力、回正力矩 Compliance 扫掠（Level 台架模式）

### 2.3 MBD 时域引擎（S5，先设计后实现）

- **公式化**：Index-3 DAE（q, v, λ）：M q̈ + Φ_qᵀ λ = f；几何约束 Φ(q)=0
- **积分器**：
  - 隐式：BDF-2 / 隐式梯形（HHT-α 预留），Newton 迭代解非线性方程组
  - 显式：RK4 / 辛欧拉（快速近似路径，现有 stepDyn 升级）
  - 稳定化：Baumgarte / 投影稳定化；约束漂移检查
- **刚柔混合**：刚体（现有簇）+ 柔性体（Craig-Bampton 模态缩减，S5+）
- **输入**：路面（阶跃/正弦/扫频 chirp/随机 PSD/双移线路径）、四立柱台架（各轮独立位移驱动）
- **输出**：时域曲线（位移/力/加速度）、频响（FFT 幅相）、偏频（模态峰值识别）、Anti-dive/squat 动态验证

### 2.4 数值健康体系

- 残差三件套（几何/合力/力矩）+ 迭代日志 + 收敛失败分类（SOLVER_FAILED / OUT_OF_RANGE / BRANCH_RISK）
- 基准测试集（手算、刚性不变量、镜像对称 1e-6、OptimumK 文档示例）
- 所有求解路径的结果状态如实标注（沿用可信度状态机）

## 3. 完备的拓扑与元件库（第二维度）

### 3.1 拓扑模板库（TopologyTemplate）

模板 = 组件图（节点 + 约束类型 + 元件挂点）+ 参数化硬点命名表 + 求解器适配（簇/铰链/驱动定义）。

| 模板 | 组件要点 | 状态 |
|---|---|---|
| 双叉臂 ± 推杆/拉杆（DWB PRO） | 上下叉臂铰链簇、转向节刚体、摇臂闭式、内置减振器 | 现有（成为基准模板） |
| 麦弗逊 MacPherson | 立柱-减振器轴刚体、下叉臂、转向拉杆、顶部轴承（衬套化） | S3 |
| 多连杆（五连杆 / E 型多连杆） | 多杆+车身衬套簇、转向节自由刚体 | S3 |
| 扭力梁 Twist Beam | 梁刚体 + 两衬套（扭转+垂向）+ 弹簧/减振器 | S3 |
| 整体桥 Solid Axle | 桥壳刚体、连杆定位（潘哈德/瓦特）、纵臂衬套 | S3 |

模板可**实例化 → 参数化 → 局部增删元件**；每拓扑自带合法性与 DOF 检查。

### 3.2 高级力学元件

| 元件 | 模型能力 |
|---|---|
| 螺旋弹簧 | 线性 / 曲线 k(x)（样条） / 预紧 / 串并联 |
| 空气弹簧 | F(p, x) 热力学简化：有效面积 A(x)、压力-位移表 |
| 减振器 | 速度-力曲线（双向/不对称）、温度无关；**迟滞**（Bouc-Wen 简化，S4+） |
| 防倾杆 ARB | 材料/几何扭转刚度 + 臂端运动学 + 连杆长度约束 + 端部衬套 |
| 缓冲块/限位 | 分段高次力（如 k·xⁿ 过渡线性）+ 触底/拉伸限位检查 |
| **衬套（6DOF）** | 每自由度刚度/阻尼曲线（可不对称）+ 耦合项矩阵 + 预紧 + 载荷输出 |
| 轮胎（下详） | MF 5.2 / PAC2002 子集；FTire 接口预留 |

### 3.3 轮胎模型

- **Pacejka 魔术公式（MF 子集落地，S1 即含）**：
  - Fy(α, Fz)、Fx(κ, Fz)、Mz(α, Fz)（含 γ 侧倾修正项）
  - 参数化文件 `.tir` 风格（可加载通用 MF 5.2 参数集）+ 程序内置降阶模型
- **附着检查**：摩擦椭圆利用率（沿用 V1 简化，作为无 MF 参数时的回退）
- **FTire / 更高保真**：定义接口协议（结构/参数文件/采样），S5 集成（可选插件）

## 4. 标准化工况与分析体系（第三维度）

### 4.1 K&C 台架工况组（输出"台架报告式"结果）

| 工况 | 驱动方式 | 核心输出 |
|---|---|---|
| 双轮同向跳动 Parallel Bump | 左右轮同步垂向 ±Xmm | Camber Gain / Bump Steer / RC 迁移 / MR 曲线 |
| 侧倾扫掠 Roll Sweep | 左右反向（轮 pad 模式） | Roll Center 高度与迁移、Roll Steer、RC 抗力臂 |
| 转向扫掠 Steering Sweep | 齿条/转向节转角 | Ackermann%、内/外轮转角、KPI/Caster 对抬轮效应 |
| 纵向力 Compliance | 接地点 Fx 扫掠 | Toe/Camber 随 Fx（Compliance Steer）、杆件力 |
| 侧向力 Compliance | 接地点 Fy 扫掠 | Toe/Camber 随 Fy、衬套形变 |
| 回正力矩 Compliance | 接地点 Mz 扫掠 | Toe 随 Mz、衬套力图 |

输出约定：曲线（X=行程/力，Y=指标）+ **增益表**（°/mm、°/kN、N·mm 等）+ 左右对称性检查。

### 4.2 动态工况（S2 起）

| 工况 | 输入 | 输出 |
|---|---|---|
| 四立柱台架扫频 | 正弦扫频/步进 chirp 激励 | 频响函数（FFT）、偏频峰值、阻尼估计 |
| 阶跃/正弦/脉冲 | 路面输入 | 时域位移/力/加速度 |
| 制动点头 / 加速 squat | 制动力矩/驱动力时域 | Anti-dive/Squat 动态值与几何值对照 |
| 随机路面（PSD） | 路面谱驱动 | 应力/加速度 RMS（S5 与 MBD 联动） |

### 4.3 扫掠与批处理

- 单/多变量扫掠（轮跳、转向、载荷、参数扰动）
- 工况套件（Case Suite）：一批 K&C 工况一键全跑（预算：基础四轮工况集 <3s，K&C 全套 <15s）
- 结果按（工况哈希 + 参数版本）缓存；A/B/C 方案同套件重放对比

## 5. 工程化衍生参数提取（第四维度）

| 参数族 | 定义要点 |
|---|---|
| 主销几何 | KPI/SAI、Caster、Scrub Radius、Mechanical Trail——**3D 空间投影**计算，含衬套形变后的动态（Compliance 修正）值 |
| IC / RC | 正视/侧视瞬心、3D 投影侧倾中心（高度+横向位置+随轮跳迁移）、抗力臂 |
| MR 导数矩阵 | 每轮：d(减振器行程)/d(轮跳)、d(弹簧位移)/d(轮跳)；轮端等效刚度 K_w = K_s·MR²；压缩/回弹分向 |
| Anti-features | Anti-dive / Anti-squat / Anti-lift / Jacking（%与 mm），**几何值 + 动态值双轨** |
| 载荷体系 | 四轮 Fx/Fy/Fz、总/几何/弹性/非簧载载荷转移分解、摩擦圆利用率 |
| 受力体系 | 二力杆轴向力（UCA/LCA/推拉杆/横拉杆/防倾杆连杆）、球铰 3 向反力、衬套 6 向载荷、合力/力矩残差 |
| 轮胎工作点 | 侧偏角、滑移率、Fy/Fx 利用率（MF 输出） |

所有指标注册进 **Variables Registry**（统一标识 + 单位 + 定义溯源），供任意 XY 绘图、DOE、报告引用。

## 7. 数据契约与工程化

### 7.1 对象模型（升级自 V1 三对象）

```
ComponentSet  元件/硬点/曲线/矩阵的版本化集合（模板实例 + 自定义）
ChassisDesign 整车方案 = ComponentSet × N 轴 + 整车参数（质量/CG/轴距轮距…）
AnalysisCase   工况定义（K&C 台架模式/动态事件/扫掠/DOE）
AnalysisResult 不可变结果（方案版本+工况版本+求解器状态+曲线+指标+增益表）
Session        UI 工作区（视口/对比/目标带覆盖/快照），非分析真源
```

### 7.2 存储与版本

- 文件 JSON（schema 版本号 + 迁移器），目录：`designs / cases / results / components / templates`
- 结果不可变；计算缓存键 = (设计版本 hash, 工况 hash, 求解器选项 hash)
- 导入导出：OptimumK 硬点 CSV、Adams `.dat`/`.adm`（转换器 S3）、K&C 报告（PDF/CSV S4）

### 7.3 API（/api/v3）

```
designs CRUD + versions      cases CRUD                  results（不可变，查询）
templates 列表/实例化         components（元件/曲线上传）  analyze（K&C/动态/DOE）
sweep（多变量）               sensitivity（DOE 任务）      report（生成器）
ws://solve-stream 拖拽实时
```
旧 /api/v2 兼容包装（内部转新模型），迁移完成后标记兼容期结束。

## 8. 规范、可信度与验收

### 8.1 规范（沿用并强化）

- 坐标系：X=前 / Y=左右（元数据声明）/ Z=上；**模板级规范由测试固定**
- 角度符号、单位、MR 定义、Compliance 约定全部显式化；禁止后处理特判当规范

### 8.2 可信度状态（沿用 7 状态 + 扩展）

`VALID / APPROXIMATE / NOT_APPLICABLE / NOT_IMPLEMENTED / SOLVER_FAILED / EQUILIBRIUM_FAILED / OUT_OF_RANGE` + `COMPLIANCE_DIVERGED`（K&C 衬套迭代失败）与 `MODEL_SIMPLIFIED`（无衬套/降阶轮胎）。

### 8.3 验收阈值（V1 基线）

- 几何残差 ≤0.02mm；力平衡 ≤1N / 0.1%（取宽）；力矩 ≤1N·mm / 0.1%
- 无衬套悬架 = 纯几何运动学，与既有机制求解器结果一致（回归）
- 镜像对称 1e-6；曲线无未解释跳变
- **K&C 对标**：与 OptimumKinematics 文档示例（Ref 目录 PDF）逐项数值对照；长期以台架实测数据校准
- 性能：单点 <50ms（WebSocket 流 100ms 预算）、四轮工况 <150ms、单轴扫掠 <1s、K&C 全套 <15s、DOE <60s

## 9. 研发路线（自当前资产出发）

### S1 引擎内核（对齐第一/四维度核心）
- 机制求解器容器化（纯 Python 服务化，双轨校验保留）
- **衬套 6DOF 元件 + K&C 两层迭代**（分水岭落点）
- Pacejka MF 子集 + 摩擦圆回退
- K&C 增益指标层（Camber Gain/Bump Steer/RC 迁移/MR 矩阵/Compliance Toe）
- 验证门：OptimumK 文档示例数值对照 + 无衬套回归一致

### S2 工况与 API
- K&C 四工况组（Bump/Roll/Steer/Compliance）+ 动态 4-Post 扫频（时域+FFT）
- /api/v3 版本化 + WebSocket 求解流 + 缓存
- modeler 前端迁移 v3（拖拽实时 + K&C 曲线面板）

### S3 元件库与模板完备
- 曲线元件（弹簧/阻尼/ARB/缓冲块）+ 衬套扩展（耦合项/迟滞）

## 10. 风险与边界

| 风险 | 缓解 |
|---|---|
| K&C 两层迭代发散 | 阻尼更新（Broyden）、步长折半、COMPLIANCE_DIVERGED 状态、衬套初始线性化 |

| 性能超预算 | 指标分级（轻/重）+ 缓存 + 并行 worker；先投影后高阶校验（沿用 P1 策略） |

## 11. 非目标（V1 整体）

- 不做自动"唯一最优"黑盒优化（提供敏感性/DOE）
- 不做车架有限元、空力、动力总成、差速器（接口预留）
- 不做完整 FTire/Pacejka 全参数认证（提供参数接口与降阶模型）
- 不做实时 HIL/硬件在环

## 12. 结论

本方案把现有积累（投影 GS/闭式极分解/摇臂解析、机制求解器 1e-11、整车动力学 bounce、v2 API、modeler 3D、DWB 方法论、工作台交互设计）作为地基，按六大维度补齐工业级能力，先做 **准静态运动学 + K&C 弹性运动学 + 标准工况 + 衍生指标 + Web 交互**（对标 OptimumKinematics），再做 **时域 MBD + 完备元件库 + DOE + 报告**（对标 ADAMS 层级）。

最小正确产品闭环（S1+S2 后）：
```
模板实例化 → 硬点/元件编辑 → K&C 四工况 → 增益表与曲线
→ Compliance 检查 → A/B 对比 → 敏感性 → 下一轮修改
```
