# FSAE 赛车 3D 交互仿真提示词

> 由「四冲程柴油机 3D 仿真」提示词改写而来，目标对象从柴油机整体替换为 FSAE（大学生方程式）赛车整车。
> 用于投喂给 AI 生成 3D 仿真（Unity / Unreal / Three.js）时的需求描述。

---

请生成一辆FSAE（大学生方程式）赛车的高精度3D交互仿真系统，要求如下：

## 一、结构与部件建模（全尺寸、可拆解级精度）

完整呈现所有核心零部件，包括但不限于：

- **车架与安全结构**：钢管空间桁架车架（含前环、主环、前隔板、侧边防撞结构）、防火墙、车手座椅、安全带系统、头枕
- **悬架系统（前后四轮）**：上/下A臂（叉臂，含鱼眼轴承/球铰）、立柱（Upright）、轮毂、推杆/拉杆、摇臂（Bellcrank）、减震器（含弹簧）、防倾杆
- **转向系统**：方向盘（含快拆）、转向柱、万向节、转向齿条（Rack）、横拉杆（Tie Rod）
- **轮边与制动**：轮辋（13英寸）、轮胎、制动盘、制动卡钳、轮毂螺栓
- **动力总成**：四冲程汽油发动机（如四缸600cc摩托车发动机）、进气系统（含进气限流器 Restrictor、节气门、进气歧管）、排气系统（含排气歧管、消声器）、链传动/差速器、半轴
- **制动系统**：制动踏板总成、制动主缸、制动管路（可简化示意）
- **电气与安全**：ECU、电池、线束（可简化示意）、主开关、灭火器
- **空气动力学**：前翼、多片式尾翼、端板、扩散器、底板（Undertray）

## 二、物理运动仿真（多系统精确联动）

- **悬架运动学**：支持轮跳（Bump/Rebound）、侧倾、俯仰三种工况，四轮悬架联动；推杆/拉杆—摇臂—减震器机构随轮跳精确联动，实时显示悬架行程、外倾角（Camber）、前束（Toe）变化
- **转向联动**：方向盘转角 → 转向柱 → 齿条位移 → 前轮转角，符合阿克曼几何，前束变化实时可视
- **发动机运转（四冲程循环，精确相位）**：按吸气 → 压缩 → 做功 → 排气顺序驱动曲轴旋转，活塞往复运动，气门开闭与凸轮相位严格同步；运动速度可调（支持手动拖拽旋转视角），显示当前曲轴转角及对应冲程阶段
- **制动演示**：制动踏板 → 主缸 → 卡钳的液压力传递，制动盘与卡钳夹紧动作
- **气流示意**：随车速动态变化的气流流线（前翼 → 车身/侧箱 → 扩散器 → 尾翼），可用粒子或半透明流线示意

## 三、交互与信息提示（鼠标悬浮触发）

当鼠标悬停于任一零件表面时，弹出悬浮信息卡，内容需包含：

- **零件名称**（中英文对照）
- **材料与制造工艺**（如：4130铬钼钢管、7075-T6铝合金、碳纤维复合材料、锻造钢等）
- **功能描述**（在FSAE赛车中的作用）
- **关键设计参数**（如：轮距、轴距、主销内倾角、后倾角、摇臂传动比、弹簧刚度、压缩比等）
- **当前运动状态**（如："左前轮压缩行程15mm"、"排气门开启"、"前翼攻角12°"）

## 四、视觉与呈现要求

- 采用PBR物理渲染，不同零件使用差异化材质（金属光泽、磨砂、碳纤维纹理、橡胶等）和颜色区分，并带有半透明剖视模式（可一键切换），便于观察悬架机构、管线布置及运动干涉
- 提供多视角预设（俯视、侧视、前视、车手视角、自由视角），并支持缩放、旋转、平移
- 界面整洁，带有图例和状态面板（显示车速、转速、水温、油压、悬架行程、转向角等模拟参数）

## 五、精细度目标

- 零件建模公差级别达0.1mm级视觉精度，运动间隙可见但不失真
- 所有螺栓、密封圈、垫片、扎带等细节件也应体现，但可简化为示意模型
- 运动动画帧率不低于60fps，保证流畅性

请基于以上要求，生成可直接运行或嵌入网页的3D仿真（推荐使用Unity、Unreal或Three.js实现）。
