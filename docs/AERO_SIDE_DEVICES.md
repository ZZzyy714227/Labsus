## 1. 概述：侧部空力系统的角色

方程式赛车（F1 / FSAE）的侧部空力系统承担三大任务：

| 功能 | 说明 |
|------|------|
| **下压力生成** | 底板（undertray）是整车效率最高的下压力来源（30–50%），其性能完全依赖侧部密封 |
| **散热管理** | 侧箱容纳散热器，内部管道将冷却气流组织后排出，排出的热气流可转化为推力或下压力 |
| **尾流管理** | 前轮产生的湍流尾流是最大的气动干扰源；侧部装置将尾流推离车身，保护底板与扩散器 |

各装置的位置关系（从前往后）：

```
前轮尾流 → 导流板 → 侧箱入口 → 侧箱体 → 尾部收缩
    ↓         ↓         ↓         ↓         ↓
  前翼涡   涡流密封  散热器芯   侧箱下切   扩散器 / 尾翼
                ↓                      ↓
           底板前缘齿               底板边缘栅条
                ↓                      ↓
           底板 Venturi 通道 ────→ 扩散器出口
```

## 2. 导流板 Barge Board

### 2.1 定义

安装在**前轮后方、侧箱入口前方**的垂直/近垂直大面板。F1 的标志性装置，FSAE 中可用简化版本。

### 2.2 空力机理

| 机制 | 细节 |
|------|------|
| **涡流发生** | 阶梯状后缘（stepped/cascaded trailing edge）迫使气流转化为有组织的涡结构 |
| **层级涡系** | 一个大涡（高惯性、抗破裂）+ 多个小涡（精细调控），形成叠层结构 |
| **前轮尾流管理** | 将前轮的高湍流尾流推向外侧，远离底板入口 |
| **底板供气** | 引导干净气流进入底板下方 Venturi 通道 |
| **涡流密封** | 泄出的涡流沿底板边缘滚动，形成气动"帘幕"阻挡外侧高压侵入 |

### 2.3 设计要点

| 参数 | 指导 |
|------|------|
| 后缘形状 | 阶梯状/锯齿状（cascaded），每个台阶产生一个独立涡 |
| 水平附板 | 底部可加水平小翼，产生辅助涡导入底板下方 |
| 与侧箱的关系 | 导流板 + 收缩-扩张型侧箱可使入口流速提升 **30%** |
| 布置角度 | 略向外倾斜（toe-out），加速 outwash 效应 |

### 2.4 FSAE 相关研究

- Siitonen（引用于 UGJ 论文）：加装导流板使侧箱入口流速提升 **16.67%**
- 导流板同时改善散热质量流量与底板供气质量

### 2.5 历史演变

| 时期 | 状态 |
|------|------|
| 2008 前 | 极其庞大复杂，几乎占满前轮到侧箱之间的全部空间 |
| 2009+ | Overtaking Working Group 大幅缩小尺寸限制 |
| 2022+ | 功能被整合进底板前缘入口和侧箱下切设计中 |

## 3. 侧箱 Side Pod

### 3.1 定义

车身中部、前后轮之间的突出结构。FSAE 中的核心多功能部件：**散热 + 气动一体化**。

### 3.2 双重功能

#### A. 散热

| 设计参数 | 结论 |
|----------|------|
| 入口大小 | **较小入口产生更高质量气流**（更少湍流），热交换率 +2%，阻力 -4% |
| 散热器角度 | 40°–50° 前倾；在扩张型管道中前倾散热器效果最佳 |
| 内部管道 | 入口直连散热器面 → 质量流量提升 200%，阻力系数 -8% |
| 出口百叶窗/格栅 | 顶部与侧面开通风口 → 热交换率 +33%，同时下压力翻 4 倍（射流效应） |
| 密封 | 散热器与管道的橡胶密封可增加质量流量 ~50%（Christoffersen） |

#### B. 气动

| 机制 | 说明 |
|------|------|
| **底板增压** | 侧箱使上方气流减速 → 底板**上方**压力升高 → 与底板下方低压形成更大压差 → 下压力增加 |
| **下切外推** | 侧箱下方的深凹槽（undercut）加速气流向外排出，推离前轮尾流 |
| **可乐瓶收缩** | 后部向中心线收缩，保持气流附着，向扩散器/尾翼输送干净气流 |
| **尾轮覆盖** | 侧箱出口气流覆盖后轮，显著降低开轮旋转阻力 |

### 3.3 侧箱 + 底板耦合数据

De Silva et al. (2011) 的 CFD 对比实验：

| 配置 | 热交换 (W) | 阻力 (N) | 下压力 (N) |
|------|-----------|---------|-----------|
| 基础侧箱 + 底板 | 9,776 | 33.0 | 3.5 |
| 短侧箱 + 底板 | 11,513 | 36.0 | 7.3 (+108%) |
| 短侧箱，**无底板** | 11,318 | 39.0 | **-22.0（升力！）** |

> ⚠️ **关键结论**：侧箱离不开底板。去掉底板后，侧箱下方形成高压区，产生净升力。

### 3.4 侧箱下切 Undercut

当前 F1 最重要的侧箱设计特征：

- 侧箱下方深深向内凹入
- 加速气流向外侧排出（outwash），将前轮尾流推离车身
- 排出的高速气流强化底板边缘密封涡
- 2022+ 规则通过底板边缘入口设计实现了类似效果

### 3.5 FSAE 典型材料

- **碳纤维** 2×2 斜纹编织（twill weave），比缎纹编织表面摩擦阻力更低
- 碳纤维蒙皮 + 泡沫芯 / 蜂窝夹层结构
- 真空袋压 / 湿铺或预浸料工艺

## 4. 侧裙 Side Skirt

### 4.1 定义

底板外侧边缘向下延伸的竖直面板，旨在**封闭底板下方低压区与外侧高压区之间的间隙**。

### 4.2 物理侧裙（历史）

| 赛车 | 技术 | 效果 |
|------|------|------|
| Lotus 78/79 (1977–78) | 滑动裙边接触地面 | Cₚ = -0.77（基于底板面积），180mph 产生 ~1,200kg 底板下压力 |
| Chaparral 2J (1970) | 侧裙 + 辅助风扇 | 真空级密封，底板吸力极强 |

**致命缺陷 → FIA 禁用**：侧裙机械失效 → 一侧下压力瞬间丧失 → 赛车失控。

### 4.3 气动侧裙（现代）

| 技术 | 原理 |
|------|------|
| **涡流栅条** | 底板下方的纵向栅条产生纵向涡流，形成旋转"空气帘" |
| **底板边缘翻转翼** | 外沿上翻的小翼产生类似翼尖涡的强力密封涡 |
| **前缘锯齿** | 底板入口边缘的齿状轮廓产生多道小涡加速供气 |
| **边缘开槽** | 沿底板边缘的槽口管理边界层，抑制回流 |

### 4.4 性能关键

| 参数 | 值 |
|------|-----|
| 有效间隙 | **< 2cm**；超出后效果急剧下降 |
| 最大效果 | 侧裙几乎接触地面时 → 接近完美密封 |
| 微小泄漏 | 产生纵向涡流反而**有助于**扩散器在大角度下抑制分离（可达 15°+） |

## 5. 底板边缘翼 Floor Edge Wing

### 5.1 定义

底板外侧边缘的**上翻小翼**（flip-up），通常位于后轮前方。

### 5.2 空力机理

| 步骤 | 物理过程 |
|------|----------|
| 1 | 底板下方低压 vs 外侧高压 → 压差驱动气流从侧向涌入 |
| 2 | 翻转翼使涌入气流卷起 → 形成强力纵向涡 |
| 3 | 涡流沿底板边缘向后滚动 → 旋转将外侧高压空气"卷走" |
| 4 | 涡核维持了底板边缘的低压"密封线" |

### 5.3 设计变化

- **通风口（vents）**：底板中段的扩散器状切口，排出中部低效气流
- **翻转翼 + 通风口组合**：翻转翼产生密封涡，通风口排出中部堆积的慢速气流 → 两者配合提升整体底板效率

## 6. 涡流发生器 / 栅条 / 导流片

### 6.1 侧箱肩部涡流发生器

- 装在侧箱**上表面肩部**的小型竖直鳍片
- 在型面急剧下倾处产生涡流，**防止气流分离**
- 将前轮尾流向上/外推移
- 参考：McLaren MCL33 的三片式肩部涡流发生器

### 6.2 底板栅条 Underfloor Strakes / Fences

| 位置 | 作用 |
|------|------|
| 底板外侧 | 产生外推涡流 → 侧向气动密封 |
| 底板中部 | 分割气流通道，阻止横向窜流 |
| 底板内侧 | 引导气流直接进入扩散器 |

**2022+ F1 规则**：每侧最多 **3 条**栅条。

### 6.3 百叶窗导流片 Venetian Blind Vanes

- F1 2022 前：侧箱入口前的多段小翼片阵列（cascaded small wing sections）
- 作用：多层涡流发生器，精细管理进入侧箱下切和底板的气流
- 2022 后：功能被整合进底板边缘入口设计

### 6.4 底板前缘锯齿 Floor Leading Edge Teeth

- 底板入口边缘的齿状/锯齿状轮廓（也称 "axe-head" 设计）
- 每个齿尖产生一个小涡，加速底板入口下方气流
- 产生下压力同时向底板下游输送有组织的涡流

## 7. 底板 + 扩散器 Undertray + Diffuser

### 7.1 核心地位

**整车效率最高的下压力装置**，贡献 FSAE 赛车 **30–50%** 的总下压力。所有侧部空力装置最终都是为底板/扩散器服务的。

### 7.2 Venturi 三区结构

```
入口收缩段 (converging) → 喉部 (throat) → 扩散器 (diffuser, 扩张)
    ↓                        ↓                  ↓
  加速、降压              最高速、最低压      减速升压、恢复
```

- **收缩段**：决定进入底板下方的空气质量流量
- **喉部**：最窄截面 → 流速最大、静压最低 → 产生最大吸力（下压力）
- **扩散器**：气流减速 → 压力逐渐恢复到环境压力 → **大幅降低阻力**

### 7.3 关键设计参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 扩散器角度 | **8–12°** | 超过 12° 气流分离 → 下压力崩溃 + 阻力剧烈增加 |
| 离地间隙 | 最小 ~25mm（FSAE ≥1"） | 间隙越小 → 加速越强 → 下压力越大 |
| 扩散器起始位置 | 后轴中心附近或略前 | 使低压区覆盖大部分底板 |
| 侧向密封 | 栅条/涡流发生器 + 边缘翻转翼 | 底板下压力对此极其敏感 |
| 长宽比 | 越长越好（受轴距限制） | FSAE 轴距 ~1600mm，可用底板长约 800–1000mm |

### 7.4 扩散器变体

- 单一中央扩散器
- 分离式双扩散器（左右各一）
- 侧扩散器（底板侧边的小扩散器）
- 双层扩散器（double diffuser）
- 侧扩散器 + 双层扩散器组合

### 7.5 与其他装置的耦合

| 上游装置 | 对底板/扩散器的影响 |
|----------|---------------------|
| 前翼 | 前翼涡（Y250）沿底板边缘滚动，辅助密封 |
| 导流板 | 导流板泄出的涡流进入底板入口，加速供气 |
| 侧箱下切 | 外推气流强化底板边缘密封涡 |
| 侧裙/栅条 | **直接**决定底板边缘密封质量 |
| 尾翼 | 尾翼降低基压，"向前传讯"通过扩散器增强底板全程吸力 |

## 8. 系统集成

### 8.1 全车下压力分布

| 部件 | 占总下压力比例 | 效率（L/D） | 对侧部依赖 |
|------|---------------|------------|-----------|
| 底板 + 扩散器 | 30–50% | 极高 | 完全依赖侧部密封 |
| 尾翼 | 20–30% | 中–高 | 中等（依赖扩散器供气） |
| 前翼 | 20–30% | 中 | 低（输出涡流给侧部） |
| 侧箱体 | 0–10% | 低（以散热为主） | — |

### 8.2 涡流遗产链

```
前翼 ──Y250涡──→ 导流板 ──层级涡──→ 底板边缘 ──密封涡──→ 扩散器
  │                   │                   │               │
  └──翼尖涡──→ 前轮尾流区    侧箱下切──→ 外推涡       尾翼涡
```

每个下游装置都依赖上游涡流的能量和方向。湍流（如跟车时的脏空气）导致涡流能量衰减 → 整条链级联失效 → 底板下压力可损失 **~48%**（跟车半个车身距离时）。

### 8.3 气动平衡

| 参数 | 指导 |
|------|------|
| 压力中心 (CoP) | 应接近重心 (CG) |
| 静态裕度 | CoP 略偏 CG 后方 → 高速稳定性 |
| 调校手段 | 前后翼攻角是调整 aero balance 的主要手段 |
| 侧部影响 | 底板/侧箱的 CoP 贡献偏后 → 前翼需要匹配 |

### 8.4 设计速度

FSAE 赛车典型设计速度：**14–16 m/s**（31–36 mph / 50–58 km/h），对应弯道工况。空力套件在此速度下需产生可感知的下压力增量。

## 9. FSAE 规则约束

| 规则 | 要求 |
|------|------|
| 前缘半径 | 所有翼面/气动装置前缘 ≥ **12.7 mm**（0.5"） |
| 其他边缘半径 | 端板、Gurney 襟翼、小翼、底板边缘 ≥ **3–5 mm** |
| 宽度限制 | 不超出前轮轮毂高度处的外侧面 |
| 前后限制 | 不超出前轮前方 460–762mm，不超出后轮后方 |
| 底板高度 | 离地 ≥ **1"**（~25.4mm），含底板栅条 |
| 驾驶员逃生 | 所有部件变形后仍不影响 5 秒逃生 |
| 禁止 | 动力地面效应（风扇抽吸）、机械滑动侧裙 |
