# FSAE 底盘分析软件开发设计方案（整理汇总版）

> 整理日期：2026-08-21
> 本文汇总此前多轮讨论固化的设计方案，供评审与后续开发引用。原始出处见文末 §17 索引。

---

## 1. 产品定位

### 1.1 一句话定位

> **面向 FSAE 赛车底盘硬点快速迭代的整车准静态几何与轮边受力分析工具。**

### 1.2 它是“底盘分析”，但不是以下六种工具

- ❌ 不是完整整车 CAD / 数字样车平台
- ❌ 不是车架有限元工具
- ❌ 不是空力设计工具
- ❌ 不是完整轮胎试验/轮胎模型工具
- ❌ 不是时域多体动力学软件
- ❌ 不是替工程师做最终决策的黑盒优化器

### 1.3 工程核心链路

```
几何方案建立 → 运动学验证 → 准静态载荷验证 → 部件受力验证 → 快速迭代
```
核心对象是**整车底盘方案**，核心输入是**硬点 + 车辆工况**，核心输出链路：

```
悬架姿态 → 四轮定位 → 接地点与转向轴几何 → 载荷转移 → 轮胎力利用
→ 悬架杆件和球铰受力 → 方案间工程差异
```

“快速”三层含义：计算快（交互 <100ms、扫掠可接受）、理解快（图形/曲线/残差直接说明问题）、迭代快（方案复制、工况复用、A/B 对比、回退低成本）。

## 2. 核心数据模型：三个对象，版本分离

| 对象 | 回答 | 内容 |
|---|---|---|
| **ChassisDesign**（底盘方案） | 设计了什么？ | 整车坐标系与基准、前后悬架硬点与拓扑、左右独立硬点实例（镜像模板初始化）、左右轮/轮胎参数、前轮转向系统、前后弹簧/减振器、前后防倾杆、轴距/轮距、整车质量/轴荷/CG、制动驱动分配、方案名称/版本/变更记录 |
| **AnalysisCase**（分析工况） | 在什么条件下分析？ | 名称、关联方案版本、四轮轮跳+齿条位移、heave/roll/pitch 姿态标签、ax/ay/az+制动/驱动分配、模型开关（防倾杆/轮边受力/附着检查）、求解状态 |
| **AnalysisResult**（结果） | 表现如何？ | 不可变的方案版本+工况版本引用、求解摘要、曲线、状态 |

**铁律**：结果必须绑定 `ChassisDesign version + AnalysisCase version + Solver state`——绝不允许页面指标混用不同硬点版本/扫掠范围/工况的结果。

## 3. 工况模型

### 3.1 几何输入：直接轮跳模式（V1）

- 四轮轮跳 + 齿条位移是**独立驱动量**；heave/roll/pitch 只是由四轮轮跳**反推的姿态标签**，不与轮跳同时作为独立输入
- V1 **不**根据弹簧/防倾杆/轮胎力反求车身平衡姿态（闭环属于 V2）
- 必须支持：单轮压缩/回弹、双轮同向、四轮 heave、左右差动、纯转向、轮跳+转向、差动+转向

### 3.2 外部载荷输入

`ax、ay、az + 制动/驱动比例 → 四轮 Fx/Fy/Fz`。几何输入与载荷输入可组合，但结果必须明确区分“当前姿态由什么几何输入得到/当前轮胎力由什么载荷工况得到”。

### 3.3 V1 预置工况（12 个）

静态设计位 / 前后左右单轮压缩回弹 ×4 / 前轴双轮同向 / 后轴双轮同向 / 四轮 heave / 左右差动 / 纯转向 / 轮跳+转向 / **1.3g 纯侧向 / 1.2g 纯制动 / 1.0g 纯加速**。组合工况（侧向+转向等）数据结构预留。

## 4. 统一几何机构模型

### 4.1 左右关系三件事分离

```
几何模板：可镜像初始化（mirror_left 仅作模板工具）
运动状态：左右必须独立求解
受力状态：通过整车/转向/防倾杆耦合，绝不直接镜像
```

对称基准工况下左右结果满足镜像关系——用于回归验证，不是通用计算捷径。

### 4.2 运动学层（真实双叉臂）

- 上/下摆臂：整体刚体绕两车身内铰点轴旋转
- 转向节：整体刚体；横拉杆、推杆/拉杆：长度约束
- 核心不变量：车身固定点不漂移、摆臂/转向节内部距离不变、杆长保持
- **轮跳与转向必须进入同一统一机构状态**，禁止未经验证把 bump 解 → steer 解 → 后处理拼接当作完整解

### 4.3 求解策略（P1 已冻结）

**SEQUENTIAL_PREVIEW_WITH_HIGH_ACCURACY_VALIDATION**：
- 顺序 `bump → steer` 保留为生产预览与兼容路径；
- 统一约束候选解仅作后台/按需高精度校验（16 工况中候选 12/16 为 APPROXIMATE，暂不可替换生产）；
- 顺序路径负行程最大原始残差 0.731417mm（阈值 0.02mm）——K-4 仍开放，未宣称修复；
- 分支延续、回退扫描、平滑测试是必须保留的兼容资产。

### 4.4 受力层

- 二力杆按轴向拉压：UCA/LCA 前后支杆、推杆/拉杆、横拉杆、防倾杆连杆
- 球铰输出三向反力、不传纯力矩：上下球头、摆臂内侧支点、杆端
- 四轮轮胎力**先整车层分配**，再进各轮边静力平衡，最后整车合力/力矩/左右耦合残差检查

## 5. 指标全景

### 5.1 定位角（每组都带工程因果链，禁止孤立数字）

| 指标 | 关键输出 | 工程链 |
|---|---|---|
| Camber | 静态/随行程/随转向 + **两类增益分开**（Δcamber/Δtravel 与 Δcamber/Δsteer） | 必须联系接地印迹/侧倾/载荷评价，“越负越好”无效 |
| Toe | 随行程（Bump Steer）/随齿条/随侧倾俯仰/左右差 | 方向（bump-in/out）与数值同等重要 |
| Ackermann | 实际内外轮转角、理想几何、百分比、偏差、转向中心 | 理想公式 `cotδ_o−cotδ_i = track/wb` 仅参考，不得替代真实机构 |
| KPI/SAI | 随行程/转向、主销轴线与接地点、jacking 趋势 | KPI→接地点横移→Scrub→力矩→跑偏/手感→转向 Camber→jacking |
| Caster | 随行程/转向、Trail、Steering Camber Gain、Bump Steer 联动 | Caster→Trail/回正→转向节斜轴运动→增益链 |
| Scrub Radius | 正/零/负、随行程/转向、左右差、力矩趋势（mm 距离定义） | V1 无制动盘反扭矩但不得省略接地点力臂力矩 |
| Included Angle | = Camber + KPI（符号服从统一约定） | — |
| **Motion Ratio** | 由真实几何求 `Damper Travel / Wheel Travel`、曲线、压缩回弹差异 | **禁止用固定 0.6/0.7 伪装精确值** |

### 5.2 高级几何

- **Instant Center**：正视/侧视、随轮跳、等效摆臂长、无穷远警告
- **Roll Center**：IC→接地点连线→中心线交点；随行程；明确 ≠ 时域动力学瞬时侧倾中心
- **Pitch Center / Anti-dive / Anti-squat / Anti-lift**（标注为几何比例）
- **Jacking**：侧向工况的力垂向分量、百分比、RC 过高警告
- **轨迹**：轮心/接地点/主销接地点 X/Y/Z、轴距变化、轮距变化

## 6. 整车载荷与轮胎模型（V1）

- 纯侧向/制动/加速工况使用设计姿态或指定轮跳姿态计算——准静态组合，**不宣称弹簧/防倾杆/轮胎/车身姿态闭环**（V2）
- 输出每轮 Fx/Fy/Fz + 前后轴垂载/左右垂载/纵向横向载荷转移 + 四轮合力残差 + 整车力矩残差 + 离地警告
- **载荷转移分解**：总转移 / 几何转移 / 弹性转移 / 非簧载转移（总量 ∝ m·a·hCG/track 或 /wb，悬架调的是分配与时机）
- **附着检查**：简化摩擦圆 `Fx²+Fy² ≤ (μ(Fz)·Fz)²`，输出利用率与三档状态——不宣称 Pacejka

## 7. 结果可信度与证据链（V1 必须）

每个结果携带状态：`VALID / APPROXIMATE / NOT_APPLICABLE / NOT_IMPLEMENTED / SOLVER_FAILED / EQUILIBRIUM_FAILED / OUT_OF_RANGE`。

同时显示：几何最大约束残差、受力合力残差、受力力矩残差、可达性、分支风险、是否简化轮胎/载荷模型、是否默认 MR、负载不足、摩擦圆超限、杆件/减振器超程。

**禁止**：未实现结果用空白/默认值/伪精确数字隐藏。

## 8. 数据模型迁移与 API

- 服务端版本化 JSON 存储为方案真源（V1 不引 SQLite）：
  `chassis_designs/{id}.json / analysis_cases/{id}.json / analysis_results/{id}.json`
- 旧 `DESIGN_PARAMS`/覆盖文件仅作导入源；旧 API 保留兼容包装内部转换；`mirror_left()` 仅作模板初始化
- **新 API 只接受明确的 design_id/version + case_id**；前端 localStorage 快照只作迁移前历史，不与服务端并存为第二真源
- 先新增版本化 API → 再迁移前端 → 最后标记旧接口兼容期

## 9. 坐标、符号与角度规范（先于指标，测试固定）

- X 车辆前方 / Y 左右（正方向在方案元数据中**显式声明**）/ Z 垂直向上
- 禁止 `fix_left_angles`、`toe<90°` 等后处理特判作为规范
- Camber/Toe/KPI/Caster/Scrub/Trail/Ackermann/MR 的定义、符号、单位全部显式固定并写入元数据
- 规范完成后重核左右镜像、角度符号、接地点和曲线导数测试

## 10. 验证层级、验收阈值与性能预算

**验证层级**（7 级）：向量/角度单元 → 手算硬点 benchmark → 刚性不变量 → 顺序/统一解对照 → 前后轴镜像与极端轮跳回归 → OptimumKinematics 参考对照 → 实车数据趋势（远期）

**验收阈值**（V1 基线，允许基准后调整）：
- 几何刚性长度残差：正常 ≤ **0.02 mm**（警告 >0.02，失败单独标记）
- 轮边合力残差：≤ 1 N 或外载荷 0.1%（取宽）；力矩：≤ 1 N·mm 或 0.1%
- 曲线无未解释孤立跳变（跳变须回原始求解状态排查）
- 完全镜像输入的左右结果差异：角度 ≤ 1e-6 deg、长度 ≤ 1e-6 mm

**性能预算**：
- 单轴单点运动学 < 50ms；四轮单点几何工况 < 150ms
- 25–51 点单轴扫掠 < 1s；基础四轮工况集 < 3s
- A/B 对比不得重复计算相同方案/工况哈希

## 13. 快速迭代工作台（前端子方案）

### 13.1 成功标准
- 一轮“改参数→看指标→判断好坏”闭环 ≤ 2s（含重量指标）
- 拖动参数运动学实时刷新 < 100ms；松手快速 sweep 范围指标 < 500ms；展开指标盘全量 < 2s

### 13.2 指标体系（4 维）与目标带（可逐项修改）

| 维度 | 关键指标（绿/黄/红 示例） |
|---|---|
| 运动学（前后独立） | camber 变化 Δ<3.5°/3.5–5°/>5°；camber 形态；bump steer <1°/1–2°/>2°；caster/KPI 变化；scrub 变化 <15/15–25/>25mm |
| 姿态侧倾 | roll gradient 0.8–1.5°/g；RC 高 20–60mm；RC 变化；anti-dive/squat 20–40%；jacking <5mm |
| 动力学 | ride freq 前 2.0–2.5Hz、后 2.5–3.0Hz、后/前比 1.15–1.30；阻尼比 0.5–0.9；MR 前 0.5–0.9；载荷转移分配 45–55% |
| 结构受力（3 工况） | 推杆 <1500N/1500–2500/>2500；UCA/LCA <800N；转向拉杆 <300N |

### 13.3 三级计算分级（性能路线）

| 级别 | 触发 | 覆盖 | 预算 |
|---|---|---|---|
| 轻量·单点 | 拖动中（节流 100ms） | 当前姿态瞬时值（**不做红绿灯**，只显示数值与趋势） | <100ms |
| 轻量·快速 sweep | 松手 | 范围类：bump steer、Δ变化、MR、damper travel（产生运动学红绿灯） | <500ms（25 步 PBD only，跳过 polish） |
| 重量·analyze | 展开指标盘 | 姿态+动力学+结构+全量红绿灯 | <2s |

**前置依赖**：PBD 漂移（±15mm 外）必须先在 P0 修复，否则污染快速 sweep 范围指标。

### 13.4 UI（Neo-Brutalist 工作台）
- 全局：无圆角、粗黑边框、硬阴影 `4px 4px 0 #000`；四维→强调色映射（青=运动学/橙=姿态/粉=动力学/荧光绿=受力）
- 布局：推挤式三区（参数栏 22% + 3D 78% + 底部历史条；指标盘展开时折叠为图标条），**任何面板无 overlay 遮挡**
- 顶栏达标汇总灯（如 ● 11/12）；指标盘每项 状态灯+名称+数值+目标带，点击展开曲线（目标带色带）
- 对比模式：旧值划线→新值+Δ+双灯+曲线灰虚线叠加
- 快照：调整动作结束 1s 防抖；几何或整车参数有变才记录；localStorage 上限 100 条滚动；时间线可回退/对比

### 13.5 API
`POST /api/analyze`（全量 4 维+曲线）、`/api/vehicle`、`/api/targets`、`/api/defaults`（扩展 vehicle+targets）、`/api/sweep_fast`；结果按（几何 hash+参数版本）缓存。

## 14. DWB 建模方法论支撑（参考软件反向设计）

- **模型**：固定节点（车身）+ 自由节点（摆臂/转向节/摇臂）+ 刚性线（距离约束）+ 可形变线（弹簧阻尼/轮胎）
- **刚体簇**：摆臂铰链簇（绕两车身铰点单参数最优旋转）+ 转向节自由刚体簇（质量加权极分解）+ 摇臂闭合解析（两基点轴 + 全局相角映射消分支奇点）
- **投影扫描**：铰链/刚体/距离/驱动四类投影交替；Continuation 分步逼近大跨度输入；行程极限扫描
- **几何正确性保障**：初始长度取自同一组硬点、固定点不漂移、摆臂转向节保持刚体、最大约束残差、连续分支跟踪、可视化验证
- **指标**：车轮轴/外倾/前束/接地点/主销/KPI/Caster/Scrub/Trail/IC/RC/MR/曲线导数
- **台架动力学**：弹簧+压缩回弹阻尼+轮胎垂向刚度+缓冲块；显式积分、vel 投影
- **稳定杆**：U 形扭杆几何（连杆解析定位）+ 扭转刚度 + 侧倾刚度读数

- **V2 轮胎与制动扩展**：侧偏刚度、Pacejka/简化 MF、摩擦椭圆、Slip Angle、制动盘反扭矩、回正力矩
- **V2 柔性与部件**：衬套/摆臂柔度、Compliance Steer、非线性弹簧、减振器速度特性、防倾杆应力、安全系数
- **V3 目标驱动迭代**：硬点扰动→敏感性矩阵→可行域→候选方案→多目标排序（先敏感性后优化；考虑硬约束/轮胎状态/残差/受力/奇异/目标冲突）
- **V3 以后时域动力学**：车身 6DOF、轮胎动态、路面输入、瞬态制动、双移线/恒半径/绕桩、频响、实车回放

## 16. V1 验收主流程

```
建立方案 A → 编辑前后硬点 → 检查合法性 → 前后轴轮跳扫掠
→ Camber/Toe/Caster/KPI/Scrub/Trail → IC/RC/Pitch 几何/MR/轨迹
→ 齿条位移 → 内外轮转角/Ackermann → 轮跳+转向组合
→ 1.3g 侧向/1.2g 制动/1.0g 加速 → 四轮 Fx/Fy/Fz → 载荷转移/摩擦圆
→ 各轮边二力杆/球铰反力 → 几何/力/力矩残差 → 存为方案 B
→ 同工况 A/B 对比 → 输出硬点/指标/受力/警告差异 → 决定下一轮修改
```
必须回答七问：改了哪个点？改变了什么几何？影响了哪些定位角？哪些接地和载荷？哪些杆件力？付出了什么代价？结果是否收敛闭合？
