## 第一组 · 王教授 —— 价值与准确性

### Q1. LABSUS 里哪一点是 Adams 给不了、文献里也没有的？

**答**：我不把 LABSUS 当成 Adams 的平替，它的价值在三件事。第一是**白盒**：车队里每个人都能读到每一行求解代码，Adams 是黑盒，学生只知道点按钮、不知道为什么发散；第二是**触达成本**：浏览器双击即用、离线可跑，赛道边没有加密狗、没有网络也能改硬点看曲线，这是我们车队的真实痛点；第三是**教育闭环**：它是我理解车辆动力学数值求解的载体，从几何到 K&C 到瞬态，每一层都逼我把教科书公式变成能跑的代码。

至于敢不敢拍板：**现阶段我不敢只用 LABSUS 定最终硬点**。我的用法是"LABSUS 做前期几何迭代和趋势判断，把候选方案收敛到两三个，再上 Adams 或实车 K&C 验证"。它不是替代品，是把设计空间从无穷大压缩到小集合的工具。

### Q2. 你怎么保证模拟的准确性？

**答**：把验证拆成三层。**第一层，解析特例验证**：我构造了一批有解析解的构型——上下 A 臂完全平行的双叉臂做 heave，外倾变化解析上应为零、侧倾中心应落在地面线上，代码必须精确复现；纯转向时刚体的定长约束也属于这类硬校验。**第二层，双实现对拍**：JS 内核和 Python 引擎对同一硬点集解同一组工况，K&C 曲线逐点比对。**第三层，对称性检查**：左右镜像构型的求解结果必须镜像一致（有专门的 mirror_symmetry 测试锁死）。

误差量级：解析特例在 1e-9 量级，双实现对拍在 1e-9 到 1e-12。**但我明确承认缺失的第三层：目前没有和 Adams/OptimumK 或实车 K&C 台做过正式对标**，这是当前最大的验证缺口，也是我接下来最优先要补的事。

### Q3. 和 Adams 对过标吗？差 5% 你说谁错？

**答**：没做过正式对标——我直说。我的仲裁方案分三步：第一步先用解析特例排除实现错误，这一步能拦住 90% 的问题；第二步找公开基准，OptimumKinematics 示例车型公布了 K&C 曲线，我用同硬点复现，比对 camber gain、RC 高度、bump steer 的趋势和量级，目标误差 5% 以内；第三步和车队的 Adams 席位对跑同一模型。

如果最终差 5%，我的仲裁逻辑是：**解析解不会错，谁违反几何恒等式谁错**；两边都不违反，就查输入差异——K&C 的"同一工况"在两个软件里定义并不完全一样（载荷作用点、约束自由度、参考系），很多"结果不一致"其实是工况定义不一致。

### Q4. 衬套刚度、轮胎参数、质量惯量从哪来的？

**答**：三类数据分开说，诚实程度不同。**质量与质心**：轴荷秤实测，质心高度抬升法，转动惯量 CAD 估算加 ±15% 不确定度——有实测支撑。**衬套刚度**：FSAE 上大部分连接是球铰（近似刚性），真正有弹性的是少数衬套位置，我取的是厂商样本典型值加文献量级，**没有逐件实测——这是我数据链最弱的一环**，计划借学校试验机补实测。**轮胎 MF 参数**：FSAE TTC 的 Hoosier 轮胎数据走公开渠道，用拟合系数；拿不到的部分用文献系数加敏感性分析兜底。

所以"垃圾进垃圾出"我部分接受。我的应对是：对最不确定的参数（衬套刚度、轮胎载荷敏感性）做敏感性分析，**确认结论方向对这些参数不翻转，否则就不基于该结论做决策**。仿真不能消灭不确定性，但能告诉你哪个不确定性是致命的。

### Q5. 残差 1e-13 是不是用数值精度掩盖模型不确定性？

**答**：这个问题我真实想过。1e-13 不是给"物理精度"用的，是给**"数值确定性"**用的：求解器必须保证同一输入永远得到同一输出、扫掠曲线连续无毛刺，否则 continuation 热启动和黄金基线回归全部失效。模型不确定性是另一条正交的轴，我用两件事应对：一是参数扰动 ±10% 看指标变化幅度；二是**结论级的可信度标注**——我的报告生成器对每个指标输出 VALID / APPROXIMATE 等状态，不确定性大的指标明确降级。数值精度和模型精度是两条轴，我在自己这条轴上做到极致，在另一条轴上诚实标注。

### Q6. 凭什么让人信服地使用你的软件？

**答**：第一句话会是："**你先别信软件，先信一个你能手算的数。**"然后现场给他一个平行双叉臂特例，用几何作图手算侧倾中心高度，和 LABSUS 输出对上；再让他自己改一个硬点、自己手算、再对一次。信任不是我用结论说服他，是让他亲手完成一次验证闭环。

工具层面配套三样东西：每个指标标注可信度等级、报告里写清计算口径（公式和参考系定义）、导出 JSON 让任何人可以在别的工具里复算。**软件的可信度是流程设计出来的，不是宣传出来的。**

## 第二组 · 李教授 —— 数值与建模本质

### Q7. "闭式投影迭代"是什么？和拉格朗日乘子法什么关系？

**答**：先给结论：它**不是新算法**，我诚实定位为"位置式约束投影 + 不动点迭代"，思想上接近 position-based dynamics / 非线性 Gauss-Seidel，而不是教科书约束多体动力学的拉格朗日乘子路线。具体解的方程：双叉臂被抽象为"外球铰绕内侧两点定义的定轴做圆周运动"，heave 命令下轮心位置先闭式投影到圆上（投影有解析解，所以叫闭式），转向拉杆定长约束和转向角构成残差向量，交给最小二乘联合收敛。

和乘子法的本质区别：我不解 DAE，几何投影硬满足一部分约束、剩余耦合约束当最小二乘残差软收敛。**代价**是理论上不如乘子法优雅、拿不到拉格朗日乘子（即约束反力），**收益**是数值上极其皮实、不需要 DAE 指标约减。简历上"自研"指的是这套混合方案的工程组合是我自己做的，不是发明了新数值方法——这一点我从不含糊。

### Q8. 为什么用最小二乘？哪些约束是"软"的？

**答**：残差构成是转向拉杆定长残差加轮心目标位置残差，未知数是立柱 6 自由度位姿加转向输入，残差个数确实可能多于未知数——左右两侧耦合进同一个方程组时。**"软"的只是拉杆定长那部分残差**，A 臂圆周约束是投影硬满足的；但"被牺牲精度"这个说法不成立——**收敛判据用的是所有残差的 max 范数而不是 L2**，就是为了保证最坏的那个约束也达到容差，所以每个约束都满足到容差级，只是不都精确为零。

选最小二乘而非直接解非线性方程组的原因：残差构成随工况变化、雅可比可能秩亏，最小二乘框架天然处理超定和秩亏，scipy 的 TRF 自带数值雅可比和信赖域，工程上最皮实。

### Q9. 信赖域 vs 线搜索？发散了怎么办？

**答**：线搜索先定方向再定步长；信赖域先限定一个步长球，在球内让局部二次模型最优——雅可比病态、二次模型不可信时信赖域稳得多，TRF 是带边界反射的实现。**发散我亲眼见过**：换整套硬点、初值差得远时，一步求解直接失败。我的解法是 continuation：把命令分成小步（每步几毫米量级），上一步的解做热启动逐步逼近，单步失败会自动再细分。奇异位形（A 臂内外点近共线导致投影轴退化）的处理是近共线检测加正则化，同时把结果状态降级——**我的原则是宁可输出 APPROXIMATE，也不静默给出一个看似收敛的错误解**。

### Q10. 当场数自由度（Grübler / Kutzbach）

**答**：分两层说。**教科书理想化模型**：把双叉臂抽象为 4 个运动体（立柱、上臂、下臂、转向拉杆）加理想运动副（两个车架转动副各约束 5、四个球铰各约束 3），Kutzbach 公式 F = 6×4 − 22 = **2**——轮跳 1 个 + 绕主销转向 1 个，所以 heave 配 rack=0 时机构有唯一解。**但我实际的数据模型不是这个理想化**：节点 + 刚线 + 旋转簇的实现是几何超静定的，按"3N − Σ约束"做秩加和会得到负数或误导值——所以代码里把 dof() 定义为"传动自由度"= 轮跳 + 齿条 = 2，它不靠数出来、靠求解器收敛测试验证（±30mm heave 与 ±rack 下残差 < 1e-5）。"理想化能数、实现里只能验证"这个差别是我写求解器时真实踩过的坑。退化情形：A 臂内外点接近共线时旋转轴定义退化、投影雅可比秩亏，处理是检测近共线、轻微正则化、状态降级。

### Q11. 衬套 6DOF 和机构重解怎么耦合？Anderson 加速的是什么？

**答**：外层变量是衬套 6 维位移 δ（3 平移 + 3 旋转），残差是**力平衡 r(δ) = f_ext − bush_force(δ) = 0**，bush_force 是衬套刚度阵乘 δ。外层每试探一组 δ，内层要重新解一次机构保证几何一致——所以是嵌套迭代。因为力差除以刚度就是位移修正，简单不动点形式是 δ_{k+1} = δ_k + r(δ_k)，**Anderson 加速的就是这个不动点**：用最近 3 步历史构造组合步（混合系数 β=0.5），单步限幅 5mm，收敛阈值 1e-6。主路线是 TRF（带数值雅可比），数值雅可比病态失败时 Anderson 兜底。当前简化：外载只含平移分量、旋转自由度无外力矩；接地点六分力到衬套锚点的静力映射（二力杆传力）在规划中。

### Q12. "侧倾一阶滞后"的物理依据？极限工况还能用吗？

**答**：依据是时间尺度分离：FSAE 侧倾固有频率约 1.2–1.5Hz、阻尼比 0.6–0.7，侧倾稳态建立时间在百毫秒量级，而赛道仿真的轨迹层关心的是更慢的车体平面运动——所以侧倾建模为"准静态目标值加一阶指数趋近"，时间常数 τ ≈ 1/(2π·f_n) ≈ 0.15s。**这个系数是工程近似，不是辨识结果，我承认。**

能力边界：载荷敏感 MF 轮胎让纵横向非线性部分进入模型，1g 量级的稳态转向和移线瞬态可信；极限工况不行——侧倾非线性（缓冲块触碰、防倾杆行程限位）没有建模，那需要 7 自由度以上模型。所以赛道仿真的圈速我当**相对比较工具**用：两个调校方案谁快，比"绝对圈速是多少"可信得多。

> **组二点评（李教授）**：题 7 的定位诚实（工程组合而非新算法）是加分项；题 10 现场 Kutzbach 数对了（F=2）；题 12 主动划边界。通过。
> **提醒**：题 7 说出"拿不到约束反力"——乘子法恰好给反力，你未来做强度校核会撞上这块短板，建议补一个乘子法对照实现。

## 第三组 · 张教授 —— 工程与可信度

### Q13. 单文件 7500 行，为什么不模块化？

**答**：动机是分发约束不是能力问题：车队场景要双击即用、离线可用、零安装，单文件是这个约束下的最优解，React 加构建链会毁掉它。代价我清楚：没有类型检查、没有 lint、重构靠人肉。**爆炸半径评估**：加多连杆拓扑动的是求解内核，约占文件 30%，渲染层和 UI 层基本不动——因为机构数据和视口绘制是分离的，四视口共享全局机构状态。长期迁移路径：文件内部已按 banner 注释划了模块边界，可以拆成 ES modules 上 Vite，打包产物仍可以是单文件。反思：应该更早上 JSDoc 型类型检查（零构建成本），我加晚了。

### Q14. "数值逐位对标"敢立军令状吗？

**答**：不敢，我说实话：parity 测试比对的是**行为等价不是逐位等价**——同一硬点集下 JS 内核与 Python 引擎的 K&C 输出在相对容差 1e-9 量级一致。理论上 double 下求和顺序不同、超越函数 libm 实现不同都有 ULP 级差异，经迭代可能放大到 1e-12~1e-10，所以"逐位"是 README 里的修辞，工程验收标准应该是"容差级一致 + 黄金基线回归"。真要立逐位军令状，手段是把两边运算顺序和超越函数实现对齐——我认为不值：对工程曲线场景，容差级一致性完全够。

### Q15. 77 个测试怎么分层？基线怎么防自欺？

**答**：四层。**几何真值断言**约 20 项：解析特例（平行臂 heave 外倾恒零、镜像对称构型结果镜像一致、Strut 拓扑闭式解对照）；**物理回归**约 15 项：compliance 力平衡、衬套、MF 轮胎、瞬态的量级与能量合理性；**API 集成** 29 项：v3 接口 schema、错误路径、整车求解；**门禁/基线**：s1_gate 状态门禁、指标管线治理测试、tphys_parity 双实现对拍。**property-based 没有系统化**——随机硬点生成器有（用于压力测试），但没接 hypothesis 做属性断言，这是我明确的欠账。基线防自欺：基线文件进版本库，更新必须在 git diff 里显式可见，配合指标管线治理测试锁死计算路径——改基线等于改代码，review 必然可见。

### Q16. Python 引擎在实时交互里到底扮演什么角色？

**答**：三件前端做不了或不应做的事。**权威数值**：K&C 四工况全扫掠、整车含载荷转移求解、1000Hz 子步的赛道瞬态——这些计算量会打崩浏览器交互帧率，拖拽走本地 JS 只解"单点姿态"这个轻问题；**单一真源**：前端内核与引擎互为对拍基准，重决策用引擎曲线，交互探索用前端；**演进平台**：衬套力平衡、MF 轮胎这些重模型只在引擎实现。架构逻辑是"交互在边、计算在心"，不是为架构而架构。

### Q17. localStorage 两标签页互覆怎么办？

**答**：这是真实缺口，我承认。现状：单标签页自动写盘 + 导出 JSON 兜底，双标签页同时开同一份硬点会静默互覆。代价评估：车队场景单人单机为主，碰撞概率低但后果是白干一下午。修复方案已想好：写盘带时间戳和内容摘要，加载时发现存储比内存新就弹窗二选一；连引擎时服务端再留一份。**优先级我排在静力层之后**——数据竞争是低频问题，静力层缺失是"功能不存在"问题，缺陷排序本身也是工程判断。

### Q18. Canvas 2D 瓶颈 profile 过吗？100 硬点先死在哪？

**答**：profile 过，performance.mark 打点。当前规模瓶颈排序：Canvas 2D 路径指令数 > 每帧图元深度排序 > JS 求解。几百图元规模下四视口全量重绘每帧几毫秒，60FPS 有余量；拖拽时 K&C 扫掠节流到 140ms 一次、每次 45 步，避免和拖拽求解抢主循环。**100 硬点先死在 draw call**：路径指令随图元线性涨，先突破 16ms 帧预算的是渲染不是求解，届时该上 WebGL 批量线渲染（一次 draw 画所有线段）——方案我知道，当前规模不触发，不为未来性能过度设计。

> **组三点评（张教授）**：题 17 的缺陷排序、题 18 的"不过度设计"是成熟工程判断；题 14 主动纠正自己 README 的修辞——通过。

## 第四组 · 陈教授 —— 实车与诚信

### Q19. 巴哈悬架刚度阻尼怎么定的？实车暴露了什么问题？ ⚠️

**答**：（⚠️ 以下必须替换成你的真实数据）流程：先定设计目标——越野赛道抓地优先、行程 200mm+，偏频前 1.6Hz 后 1.9Hz 配平（后高前低抗制动点头）；阻尼比压缩 0.5、复原 0.7 偏复原；后轴防倾杆补转向不足。实车暴露两个问题：满轮跳行程时转向拉杆与半轴护套干涉、连续颠簸中复原不足出现"漂浮感"——解法是垫片错位加更换低速压缩阀片。赛前计算 vs 实车：行程和运动趋势全对上，但实车平衡比计算更偏不足转向，事后归因是胎压设定和滚动阻力矩估算偏低。

### Q20. 飞坡按几个 g？安全系数多少？ ⚠️

### Q25. 主销后倾为什么产生回正力矩？（现场推）

**答**：（画侧视图）主销轴线后倾 γ，轴线与地面交点在接地印迹中心**前方**，距离为机械拖距 d ≈ R·tanγ（R 为轮胎滚动半径）。转弯时地面给轮胎侧向力 Fy，作用在接地印迹上，它对主销轴线的力臂就是 d（严格处理还要乘主销内倾的投影修正系数），产生绕主销轴的回正力矩 M = Fy·d。叠加气动拖距：接地压力中心在印迹几何中心后方 e，同样贡献 Fy·e 的回正力矩。**总回正力矩 = Fy·(d + e)**。关键物理：接近附着极限时，压力中心前移使 e 先增后减，极限处回正力矩骤降——这就是极限下方向盘"变轻"的来源，也是 caster 不能凭感觉加大的原因。

### Q26. 稳定性因数 K？（现场写）

**答**：横摆角速度增益 ωr/δ = (v/L) / (1 + K·v²)。以**正侧偏刚度约定**推导：稳态下前后轴侧偏力之比由力矩平衡定为 Fyf/Fyr = b/a，代回侧偏角关系可得 **K = (m/L²)·(b/Cαf − a/Cαr)**（教材用负侧偏刚度约定，形式差一个负号，物理一致）。判据：K>0 不足转向，增益有极值，特征车速 v_ch = 1/√K；**K<0 过多转向**，增益随速度无限增大，临界车速 **v_cr = 1/√(−K)**，超过即横摆发散需主动修正。稳态回转试验判据：定半径渐进增速，测前轮转角随侧向加速度的变化，dδ/day > 0 为不足转向；等价地测前后侧偏角差 (αf − αr) 对 ay 的符号。

### Q27. 侧倾中心为什么用力中心法而不是几何法？

**答**：几何法假设全部侧向力沿"接地中心—瞬时中心"这条线传递到簧上质量；力中心法（LCF）反过来，用**悬架连杆实际分担的侧向力除以总侧向力**定义等效高度。两者在侧向力不全走摆臂的悬架上是分开的：麦弗逊的减振器柱分担侧向力、几何法高 IC 时失真。我的 LABSUS 用 LCF 口径，因为准静态载荷转移（TLLTD 三路径分解）需要"力从哪条路径走"的力一致口径。**这是我踩过的坑**：第一版实现的几何法，做载荷转移分解时对不上，换成力中心法才闭环——所以这题我不是背的，是修出来的。

### Q28. 为什么工程偏爱 2-范数？离群硬点会怎样？

**答**：三个理由：可微、有闭式正规方程、对应高斯噪声假设的极大似然，配套算法生态（信赖域、正规方程求解器）最全。1-范数对应拉普拉斯假设，中位数式、抗离群，但不可微要走 LP / IRLS；无穷范数是极小极大，只管最坏约束。**离群硬点的后果**：最小二乘把一个错误残差摊到所有未知数上，整体位姿被拉偏。我防了两道：输入端硬点坐标范围校验；求解端 scipy 的 loss 参数可切 soft_l1（Huber 类鲁棒损失），默认线性 loss 但我知道开关在哪。

# 附录 · LABSUS 核心模型假设清单（按求解层，每条含"破在哪"）

> 面试用法：假设类问题的满分结构 = **假设内容 → 买到什么 → 破在哪 → 升级路径**。以下全部核对过引擎源码（models.py / forces.py / compliance.py / bushing.py / transient.py），敢在面试里说"代码注释里就是这么写的"。

## L0 · 世界观：机构 = 点 + 刚线 + 旋转簇

**假设**：一切物理构件被抽象为几何对象——节点（Node）、刚线（Link, kind='R'，'E' 弹性线预留）、轴向旋转簇（铰链/摇臂，成员相对锚点按设计位锁定）、刚体簇。没有截面、没有质量分布、没有外形。
**买到**：求解器只处理坐标和距离约束，几何投影可全部闭式化，毫秒级收敛。
**破在哪**：任何依赖构件形状/柔性/质量的物理都不存在——A 臂弯曲、摇臂惯性、零件干涉只剩"视觉穿模"级别的检查。
**升级**：弹性线（'E'，已预留）→ 柔性体（模态综合）。

## L1 · 运动学层：命令驱动的纯几何

1. **构件刚体 + 球铰理想**（无间隙、无摩擦、不传力矩）。主销轴 = 上下外球铰连线，立柱绕它转。
2. **转向拉杆定长硬约束**，转向输入 = 齿条位移。
3. **推杆上端固接车架、长度是从动输出**——这是最容易被拷的一条：**弹簧/减振器的力不反馈到机构位形**。悬架运动是"命令驱动"（heave/rack 给定 → 解位形），不是"力平衡决定位形"。
   - 买到：双输入唯一解、拖拽实时 60FPS。
   - 破在哪：一切"力改变姿态"的物理进不来——气体弹簧压力变化引起车高漂移、气动升力改变姿态、非线性弹簧下的静态下沉都得靠外部给命令，模型自己算不出。
   - 升级：T5 静力层接上后 → 力-位形耦合迭代（就是在做的方向）。
4. **自由度不数、靠验证**：代码注释明示双叉臂实现是几何超静定，"3N−Σ约束"秩加和会得负数；dof() 定义为传动自由度=2（轮跳+齿条），由收敛测试背书（±30mm/±rack 残差<1e-5）。——这条是 Q10 的展开。
5. **机构求解无惯性、无重力**：纯几何求解（Node 结构里有 mass/vel 字段，是 PBD 遗产，运动学路径不用）。

## L2 · 静力层：桁架式传力（二力杆）

6. **二力杆假设**（forces.py 文档字符串原文）：杆件只有轴向拉压；球铰 3 向反力、不传纯力矩。**真实 A 臂是两端固定的梁、能扛弯矩**，在力模型里被压成一条线。
   - 买到：静力层变成桁架，线性方程组可解。
   - 破在哪：杆件弯曲应力、摇臂轴弯矩、侧向力引起的 A 臂弯曲全部看不见——**这个力不能直接拿去做强度校核**（要做也得加上弯曲修正）。
7. **超静定 → 最小范数最小二乘仲裁**：载荷在冗余传力路径间怎么分，不是物理决定，是数学（最小范数解）决定，结果标 APPROXIMATE。
8. **外载只有平移分量**：compliance 的 S1 外载仅 3 个平移分量、旋转自由度无外力矩；"接地点六分力 → 二力杆 → 锚点合力"的映射（T5）尚未接入。
9. **衬套现状 = 平移刚度 + 预紧**：6DOF 元件库里阻尼、6×6 耦合矩阵都实现了，但**没有工况注入非零耦合/阻尼/旋转力矩**（代码注释原话"S3+ 载荷阶段能力"）。即：线性（或查表）平移刚度衬套，无迟滞、无旋转刚度参与——这是 Q4"数据链最弱一环"的另一半。

## L3 · K&C / 准静态层

10. **双层解耦迭代**：衬套力平衡（外层）与机构重解（内层）交替收敛，假设衬套变形小、迭代不发散（发散有 Anderson 兜底）。
11. **载荷转移一步滞后破环**：准静态里载荷转移依赖 ay、ay 又依赖载荷转移——用上一步的 ay/gx 把环解开。假设采样步内载荷变化小。
12. **侧倾中心用力中心法（LCF）**（Q27 已答，从略）。
13. **悬架特性一维参数化**：瞬态里悬架行为经 K&C 查表（按该轮 travel 单变量线性插值）进入——假设悬架特性可以只用"该轮行程"一个变量描述，行程×侧倾×纵向加载的交叉耦合不在表里。

## L4 · 瞬态层（赛道仿真）

14. **车体平面 3-DOF**（6 状态 X/Y/ψ/vx/vy/r）：侧倾、俯仰不是状态，是准静态代数解 + 一阶滞后滤波（τ 是工程近似不是辨识值）。假设侧倾/俯仰建立时标远大于平面运动时标。
15. **轮胎 MF 子集**：松弛一阶滞后（τ=Lσ/vx）、外倾推力线性增益 Cγ、摩擦圆 lat_avail=√((μFz)²−Fx²)、单一 μ 系数。**无热、无磨损、无胎压敏感、点接触、平滑路面无包络**。
16. **动力与气动参数化**：扭矩-恒功率包络 min(T/R, P/v)、固定前后分配比——无换挡动力中断；气动 k·v² 常系数、无姿态敏感。
17. **驾驶员 = 纯追踪 + PI**：仿真结论的有效性受驾驶员模型带宽限制——极限工况下的"圈速"里混着驾驶员模型的局限。
