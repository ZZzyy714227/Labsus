# 第 10 章 准静态整车平衡与 3 轮侧倾闭环迭代

---

## 1. 物理图景与工程痛点

在车辆进行稳态圆周过弯或准静态变道时，侧向加速度 $a_y$ 在簧载质量质心产生离心侧向力 $F_y = m_s a_y$。该力不仅使车辆产生向外的侧滑，更驱动车身绕空间倾斜的**侧倾轴线（Roll Axis）**发生侧倾偏转 $\phi$。

在准静态操稳建模中，经典教材的单公式静态估计存在严重缺陷：
1. **P-$\Delta$ 几何负刚度效应 (P-Delta Instability)**：当车身发生侧倾时，质心离开对称中心平面，重力在侧向产生倾覆附加力矩 $m_s g h_{arm} \sin\phi$。若侧倾刚度不足，系统将触发几何奇异失稳；
2. **瞬心迁移与轮端刚度非线性耦合**：随着车身侧倾，外侧悬架压缩、内侧悬架拉伸，左右轮安装比 $MR(tr)$ 发生不对称变化，侧倾中心高度 $z_{rc}$ 实时上下迁移；
3. **闭环平衡收敛算法**：如何用稳健的迭代算法（LABSUS 3 次迭代闭环收敛）精确求出任意侧向加速度下的真实稳态侧倾角与车身姿态。

## 2. 底层数学力学严密推导

```
                      +Z (Up)
                       |
               [质心 CG: ms · g · sinφ 附加倾覆力矩]
                       |
                       |  h_arm(φ) = h_cg - z_ra(φ)
                       v
         [空间侧倾轴线 Roll Axis: z_ra = (b/L)·z_rc,f + (a/L)·z_rc,r]
                       |
        +--------------+--------------+
        |                             |
  [前轴侧倾刚度 K_φ,f]          [后轴侧倾刚度 K_φ,r]
```

### 2.1 空间倾斜侧倾轴线与侧倾力臂几何定义

设前轴侧倾中心高度为 $z_{rc,f}$，后轴侧倾中心高度为 $z_{rc,r}$，轴距为 $L = a + b$。
空间侧倾轴线连接前后侧倾中心，其在质心纵向位置（距前轴 $a$、距后轴 $b$）处的高度为：
$$z_{ra} = \frac{b}{L} z_{rc,f} + \frac{a}{L} z_{rc,r}$$

簧载质量质心相对侧倾轴线的空间侧倾力臂（Moment Arm）为：
$$h_{arm} = h_{cg} - z_{ra} = h_{cg} - \left(\frac{b}{L} z_{rc,f} + \frac{a}{L} z_{rc,r}\right)$$

---

### 2.2 准静态侧倾力矩平衡方程与 P-$\Delta$ 失稳判据

在侧向加速度 $a_y$ 下，作用在簧载质量上的总侧倾力矩由**离心力驱动矩**与**重力 P-$\Delta$ 几何附加倾覆力矩**共同构成：
$$M_{\phi,drive} = m_s a_y h_{arm} \cos\phi + m_s g h_{arm} \sin\phi$$

抵抗侧倾的总弹性恢复力矩由前悬架、后悬架主弹簧及防倾杆（ARB）提供：
$$M_{\phi,resist} = K_{\phi,tot} \cdot \phi = (K_{\phi,f} + K_{\phi,r}) \cdot \phi$$

联立力矩平衡方程 $M_{\phi,drive} = M_{\phi,resist}$，对于微小侧倾角（$\sin\phi \approx \phi, \cos\phi \approx 1$）：
$$m_s a_y h_{arm} + m_s g h_{arm} \phi = K_{\phi,tot} \phi \implies \phi = \frac{m_s a_y h_{arm}}{K_{\phi,tot} - m_s g h_{arm}}$$

#### P-$\Delta$ 几何负刚度失稳定理：
* **稳定临界条件**：系统总侧倾刚度必须严格大于重力倾覆负刚度：
  $$K_{\phi,tot} > m_s g h_{arm}$$
* **失稳奇异点**：若 $K_{\phi,tot} \le m_s g h_{arm}$，分母 $\le 0$，物理上意味着车身侧倾恢复力矩不足以抵消重力侧向偏置，**车辆在侧向力下将发生灾难性的侧翻失稳（Rollover Singularity）**。

---

### 2.3 3 轮非线性侧倾闭环迭代算法

为了精确计入侧倾过程中大角度几何非线性、摇臂安装比变化以及侧倾中心迁移，LABSUS 采用了 **3 轮自洽场闭环迭代算法（3-Iteration Roll Coupling Loop）**：

```
+-------------------------------------------------------------------------------+
| 初始步: 线性估计侧倾角 φ^(0) = (ms · ay · h_arm) / (K_φ,tot - ms · g · h_arm)       |
+-------------------------------------------------------------------------------+
                                      ↓
+-------------------------------------------------------------------------------+
| 第 k 轮循环 (k = 1, 2, 3):                                                    |
| 1. 根据当前侧倾角 φ^(k-1) 计算左右四轮动态行程: tr_w = ± (Track / 2) · sin(φ^(k-1))    |
| 2. 查表/调用机构求解器获取四角瞬态轮端刚度 Kw_i(tr_w) 与动态侧倾中心 z_rc,f, z_rc,r |
| 3. 更新动态侧倾力臂 h_arm^(k) 与非线性弹性恢复力矩 M_resist(φ)                         |
| 4. 牛顿步长修正: φ^(k) = φ^(k-1) - (M_resist - M_drive) / (K_eff - ms·g·h_arm)       |
+-------------------------------------------------------------------------------+
                                      ↓
+-------------------------------------------------------------------------------+
| 输出: 绝对收敛的稳态侧倾角 φ*、全车姿态与 4 轮动载荷                                |
+-------------------------------------------------------------------------------+
```

**工程收敛准则**：实测经验表明，在正常底盘刚度（Roll Gradient $\le 5^\circ/g$）下第 3 轮迭代残差通常 $< 10^{-6}\,$rad；刚度接近 P-Δ 临界（§2.2）时该迭代不保证收敛，应改用割线法或加密载荷增量。

## 3. 核心控制变量与参数灵敏度分析

## 4. LABSUS 代码实现与数值稳定性技巧

### 4.1 核心代码映射
* **准静态侧倾耦合求解**：[`engine/src/api/chassis.py`](file:///c:/Users/zzy/Desktop/New_suspension/LABSUS/engine/src/api/chassis.py#L194-L364) 中的 `quasi_loads()`。下方为**简化伪码**（省略引擎实际的侧倾中心迁移与刚度插值环节，故循环看似重复）：
  ```python
  def _solve_roll_coupling(ms, ay_g, h_cg, z_rc_f, z_rc_r, K_phi_f, K_phi_r, a, b):
      L = a + b
      phi = 0.0
      # 3 轮闭环迭代
      for _ in range(3):
          z_ra = (b * z_rc_f + a * z_rc_r) / L
          h_arm = max(0.05, (h_cg - z_ra) / 1000.0) # 转为米
          M_drive = ms * (ay_g * 9.81) * h_arm * math.cos(phi) + ms * 9.81 * h_arm * math.sin(phi)
          K_tot = K_phi_f + K_phi_r # N·m/rad
          # P-Δ 负刚度保护
          denom = max(100.0, K_tot - ms * 9.81 * h_arm)
          phi = (ms * (ay_g * 9.81) * h_arm) / denom
      return phi, phi * (180.0 / math.pi)
  ```

## 5. 手把手工程数值算例 (Worked Example)

### 算例背景：轻型原型赛车在 1.2g 侧向加速度下的 3 次侧倾迭代手算（所得 2.99°/g 为本例软刚度设定值，高于 §3 表 GT3 典型 1.2~1.8°/g——参数为演示迭代过程而选，非 GT3 标定）
已知赛车参数：
* 簧载质量：$m_s = 1150.0\,\text{kg}$
* 轴距与质心位置：$a = 1.25\,\text{m}, b = 1.40\,\text{m}, L = 2.65\,\text{m}$
* 质心高度：$h_{cg} = 420.0\,\text{mm} = 0.42\,\text{m}$
* 前/后侧倾中心高：$z_{rc,f} = 45.0\,\text{mm}, \; z_{rc,r} = 65.0\,\text{mm}$
* 前轴侧倾刚度：$K_{\phi,f} = 45,000.0\,\text{N}\cdot\text{m/rad}$
* 后轴侧倾刚度：$K_{\phi,r} = 38,000.0\,\text{N}\cdot\text{m/rad}$
* 总侧倾刚度：$K_{\phi,tot} = 83,000.0\,\text{N}\cdot\text{m/rad}$
* 侧向加速度：$a_y = 1.20g = 1.20 \times 9.81 = 11.772\,\text{m/s}^2$

#### 步骤 1：计算侧倾轴线高度与力臂
$$z_{ra} = \frac{1.40 \times 45.0 + 1.25 \times 65.0}{2.65} = \frac{63.0 + 81.25}{2.65} = \frac{144.25}{2.65} = 54.434\,\text{mm} = 0.05443\,\text{m}$$
$$h_{arm} = 0.420 - 0.05443 = 0.36557\,\text{m}$$

#### 步骤 2：P-$\Delta$ 重力负刚度与分母校验
重力倾覆负刚度项：
$$K_{p\_delta} = m_s g h_{arm} = 1150.0 \times 9.81 \times 0.36557 = 4,124.2\,\text{N}\cdot\text{m/rad}$$
有效恢复刚度：
$$K_{eff} = K_{\phi,tot} - K_{p\_delta} = 83,000.0 - 4,124.2 = 78,875.8\,\text{N}\cdot\text{m/rad} > 0 \quad (\text{系统绝对稳定})$$

#### 步骤 3：第 1 轮迭代求解
$$M_{drive}^{(1)} = m_s a_y h_{arm} = 1150.0 \times 11.772 \times 0.36557 = 4,949.0\,\text{N}\cdot\text{m}$$
$$\phi^{(1)} = \frac{4949.0}{78875.8} = 0.062744\,\text{rad} \approx 3.595^\circ$$

#### 步骤 4：第 2 轮非线性余弦修正迭代
代入 $\cos(0.062744) = 0.99803$（离心力驱动矩随侧倾角减小，P-$\Delta$ 项已并入 $K_{eff}$ 分母）：
$$M_{drive}^{(2)} = m_s a_y h_{arm} \cos\phi^{(1)} = 4949.0 \times 0.99803 = 4,939.2\,\text{N}\cdot\text{m}$$
$$\phi^{(2)} = \frac{4939.2}{78875.8} = 0.062621\,\text{rad} \approx 3.588^\circ$$

#### 步骤 5：第 3 轮精密收敛
$$M_{drive}^{(3)} = 4949.0 \times \cos(0.062621) = 4939.3\,\text{N}\cdot\text{m} \implies \phi^{(3)} = 0.062621\,\text{rad} = 3.5881^\circ$$
* 第 3 轮与第 2 轮残差 $< 10^{-6}\,\text{rad}$，迭代收敛；侧倾梯度为 $\frac{3.5881^\circ}{1.2g} = 2.99^\circ/g$。
