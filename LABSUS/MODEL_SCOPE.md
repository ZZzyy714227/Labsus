# MODEL_SCOPE · 模型完整性登记表

> **这份文件回答一个问题：这个仿真器到底建了什么、简化了什么、边界在哪？**
>
> 它不追求"和真车一致"——本项目**不做实车标定**。它追求的是：任何一项物理，
> 要么在位，要么**明确登记"缺什么、影响哪个指标、方向如何"**。这样"不标定"也不会
> 损害内部可靠性，因为你知道每个数字的可信边界。
>
> 更新规则：**改动物理模型（自由度/本构/约束/数值）必须同步本表**，并在
> `docs/superpowers/specs/` 留重标记录。不更新本表的物理改动视为未完成。

---

## 一、读法：三态

| 标记 | 含义 |
|---|---|
| ✅ **在位** | 有状态/本构/断言，可被测试覆盖 |
| ⚠️ **缺** | 未建模；必须写清"影响哪个指标 + 方向 + 量级" |
| ⛔ **有意不做** | 明确取舍，附理由（不是遗忘） |

**验收口径**：随便挑一项物理改动，都能在本表指到"改的是哪一格、影响哪几层"。

## 二、范围声明（2026-11-19 定稿）

**本项目是内部研发工具，不是经外部验证的工程仿真器。**

| 可以宣称 | 不能宣称 |
|---|---|
| 改动没有破坏既有行为（L0 回归锚） | 与实车/台架一致（无 L4 数据） |
| 模型满足这些物理不变量（L1 解析锚） | 与商业软件同量级（L3 基本空缺） |
| TPHYS 这一条链双端一致（L2 局部） | 15-DOF 内核经过外部验证 |
| 参数来自合理假设且有边界登记 | 绝对精度 |

> 因此 README 不得写"深度对标 OptimumKinematics 与 ADAMS/Car"这类**精度**表述；
> 只能说"架构分层参考其思路"。详见 `VERIFICATION.md` 与本文 §七。

## 四、K1（主舞台）逐轴登记

### 4.1 自由度

| 项 | 状态 | 说明 |
|---|---|---|
| 车身 6 DOF（X,Y,Z / φ,θ,ψ）+ 体速 u,v,w + 角速度 p,q,r | ✅ | 12 状态 |
| 四轮自转 ω | ✅ | 4 状态，含反射惯量、TCS、制动 |
| 四轮垂向 zw/vzw（S13） | ✅ **默认开**（2026-11-19 转正） | 4+4 状态；`S.wheelDof === false` 才关，关时逐位复现转正前行为（特征化锚钉住） |
| 轮跳模态可观测性 | ⚠️ **实际不可见** | 预设阻尼把轮跳压到 **ζ≈1.6（过阻尼）**，自由衰减不振铃；无阻尼频率 √((Kw+kT)/mU)/2π ≈ **21.4 Hz**（formula，实算 mrF=0.598 ⇒ KwF=37.5 N/mm），也不在常说的 10~16 Hz 带内。要"看见"轮跳须先改阻尼/簧下质量（标定决策，未做，登记 P34） |
| 非簧载**横向/纵向**惯性 | ⚠️ 缺 | 未做非簧载横向 DOF；TLLTD 的"非簧载侧向惯性分量"在准静态层有、K1 无 ⇒ 大侧向加速度下轮荷分配略偏 |
| 转向柱/齿条柔度 | ⚠️ 缺（一阶滞后替代） | τ=0.05 s 代表机械量级；开环 T63 80 ms vs 真实 150~350 ms |
| 衬套柔度进时序 | ⚠️ 缺 | 柔度只在准静态层（`03-mechanism.js`），K1 无 ⇒ 动态 toe/camber 柔度低估 |

### 4.2 本构

| 项 | 状态 | 说明 |
|---|---|---|
| 轮胎纵/侧向（Pacejka MF，组合滑移 + 摩擦圆钳位） | ✅ | `magicFormula()`，含 axleScale 胎宽配平 |
